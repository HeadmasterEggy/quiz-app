题型 1　CDMA 编解码 ★★★

码分多址：每个用户一个唯一的码片序列，所有用户同时用同一频率发。码长 M，数据比特用 ±1（1 → +1，0 → −1）。

$$\text{编码：}Z_m = d\cdot c_m\qquad \text{信道：各发送方信号直接相加}\qquad \text{解码：}D = \frac1M\sum_{m=1}^{M} Z_m\,c_m$$

前提：码正交，$\langle c_i, c_j\rangle = 0$，$\langle c_i, c_i\rangle = M$。这样别人的信号在内积里贡献 0：

$$\frac1M\Big\langle \sum_k d_k c_k,\ c_1\Big\rangle = d_1\cdot\underbrace{\frac{\langle c_1,c_1\rangle}{M}}_{=1} + \sum_{k\ne1} d_k\cdot\underbrace{\frac{\langle c_k,c_1\rangle}{M}}_{=0} = d_1$$
解法步骤
  1. 先查正交：两个码逐位相乘求和，不是 0 就答 n/a。
  2. 正交：收到的信号和自己的码逐位相乘、求和、除以 M。
  3. 结果 +1 → 比特 1，−1 → 比特 0（或写 −1）。

例题（讲义）：两个发送方叠加

$c_1 = (-1,-1,-1,1,-1,1,1,1)$，$c_2 = (1,1,-1,1,1,1,-1,1)$，$\langle c_1, c_2\rangle = 0$，正交。发送方 1 发 1，发送方 2 发 −1：

$Z = c_1 - c_2 = (-2,-2,0,0,-2,0,2,0)$。用 $c_1$ 解：$(2+2+0+0+2+0+2+0)/8 = 1$ ✓；用 $c_2$ 解：$-8/8 = -1$ ✓。

Sample exam Q4：码不正交

码 (1, −1, 1, −1, −1, −1, −1) 和 (1, −1, −1, −1, −1, −1, −1)，合成 (2, −2, 0, −2, −2, −2, −2)。内积 = 5 ≠ 0。硬解得 12/7 ≈ 1.71，不是 ±1，多出来的 5/7 是对方漏进来的干扰。官方答案：两个接收方都是 n/a。

现实里还要求码片同步、各信号到达功率相同（功率控制）。

发送方 1 码 (1, −1, 1, −1, −1, −1, −1)，发送方 2 码 (1, −1, −1, −1, −1, −1, −1)，合成输出 (2, −2, 0, −2, −2, −2, −2)。接收方 1 解出的比特是？
  1. −1
  2. 1
  3. n/a
两码内积为 5，不正交，干扰无法消除。

题型 2　调度：FIFO、优先级、轮询、WFQ ★★★

  • FIFO：按到达顺序。队列满时丢谁：tail drop（丢新来的）、priority、random。
  • 优先级调度：发队列里优先级最高的；非抢占（正在发的不打断）。
  • 轮询：各类优先级相同，轮流每类发一个完整分组。
  • WFQ：广义轮询，每类按权重分份额：
$$R_i = R\cdot\frac{w_i}{\sum_j w_j}\qquad (\text{求和只算当前有分组的类})$$

例题（讲义）

优先级：分组 1–5 依次到达，1、3、4 高，2、5 低 → 服务顺序 1、3、2、4、5。3 发完时 4 还没到，就发 2；4 到时 2 正在发，不打断。

WFQ：1 Mbps，权重 2、1、1。

情况流 1流 2流 3
三条都有数据0.50.250.25
流 3 没数据0.6670.3330

空闲类的份额按权重分给其他类，不浪费。权重全相等时 WFQ 就是轮询。

分组 1、2、3、4、5 依次到达，1、3、4 是高优先级，2、5 是低优先级，非抢占优先级调度。服务顺序是？
  1. 1, 3, 4, 2, 5
  2. 1, 3, 2, 4, 5
  3. 1, 2, 3, 4, 5
  4. 1, 3, 4, 5, 2
4 到达时 2 已在发送，非抢占不打断。

题型 3　令牌桶与 QoS 原则 ★★

QoS 四条原则（H1、H2 经 1.5 Mbps 链路到 H3、H4）

#问题原则
1HTTP 突发让 VoIP 丢包，想让语音优先分组标记，路由器能区分不同类
2VoIP 发得比声明的多隔离：用监管强制源遵守分配
3固定不共享的分配，流不用满时浪费隔离的同时高效使用资源
4两个 1 Mbps 电话要走 1.5 Mbps呼叫准入：满足不了就拒绝

三种支持方式：尽力而为（无保证，靠应用）→ 区分服务（按类，软保证）→ 每连接 QoS（按流，加呼叫准入，部署很少）。

监管的三个标准

长期平均速率（每分钟 6000 个）、峰值速率（每 5 秒最多 3000 个）、最大突发（一瞬间 1500 个）。时间尺度很重要：每秒 100 和每分钟 6000 平均一样，但后者允许某一秒发 6000 个。

令牌桶

桶最多 b 个令牌，以 r 个/秒生成，满了就扔；分组拿一个令牌才能进网络。

$$N(t) \le r\,t + b\qquad t\to0:\ \le b\ (\text{突发})\qquad t\to\infty:\ \to r\ (\text{平均})$$

令牌桶 + WFQ 时延上界：桶满时 $b_1$ 个分组一起涌进队列，流 1 至少以 $R w_1/\sum w_j$ 被服务：$D_{\max} = \dfrac{L\,b_1}{R\,w_1/\sum w_j}$（前提 $r_1 \le R w_1/\sum w_j$）。例：L = 1000 bit，$b_1 = 10$，R = 1 Mbps，份额 0.5 → 20 ms。

令牌桶 r = 100 个/秒，b = 50。任意 2 秒内最多能进入网络多少个分组？
  1. 100
  2. 200
  3. 250
  4. 300
$rt + b = 200 + 50$。

题型 4　DiffServ ★★

要的是定性的服务类（白金、金、银），相对区分。可扩展的关键：核心简单，复杂的放在边缘。

位置做什么
边缘路由器每流管理，打标记（按约定的 profile：速率 r、桶 b）
核心路由器每类管理，按标记做缓冲和调度，不维护每流状态
  • 类内标记：符合 profile 的部分标绿，超出的标红（低优先级）或丢弃。Bob 约定 1 Mbps 实际发 2 Mbps → 一半绿、一半红。
  • 不符合的分组由管理员决定重新标记、转发、延迟（整形）或丢弃。

三色例子（绿 > 黄 > 红，链路 2 Mbps）

情况结果

关于 DiffServ，正确的是？
  1. 边缘路由器按每个流做标记
  2. 核心路由器按标记每类调度
  3. 核心路由器维护每个流的状态
  4. 不符合 profile 的可降级或丢弃
复杂的放在边缘，核心只看类。

题型 5　SIP ★★

目标：所有电话、视频会议走互联网，用名字或 e-mail 找人，不管对方在哪、用什么设备。服务：呼叫建立（协商媒体和编码）、找到被叫当前 IP、呼叫管理（加流、换编码、转接、保持）。

向已知 IP 呼叫（讲义）

  1. Alice → Bob：INVITE，带 Alice 的 IP、端口 38060、编码 PCM μ-law（RTP 类型 0）。描述媒体的几行是 SDP。
  2. Bob → Alice：200 OK，带 Bob 的端口 48753、编码 GSM（类型 3）。
  3. Alice → Bob：ACK。
  4. 双向 RTP：两个方向可以用不同编码。
  • 端口 5060，SIP 消息走 TCP 或 UDP；带外：信令和媒体走不同端口。
  • 不支持对方编码 → 606 Not Acceptable，列出自己支持的编码；不想接 → busy、gone、forbidden 等。

注册服务器与代理

  • 注册服务器：客户端启动时发 REGISTER：「bob@domain.com 现在在某 IP」，带有效期。
  • 代理：Alice 把 INVITE 发给自己的代理，代理把消息路由到被叫（可能经多个代理），响应沿原路返回。讲义类比：SIP 代理 ≈ 本地 DNS 服务器。
  • 完整例子：alice@umass.edu → UMass 代理 → Poly 注册服务器（重定向到 bob@eurecom.fr）→ Eurecom 注册服务器 → Bob 的机器；响应原路返回。媒体直接在两个客户端之间走，不经过代理。
关于 SIP，正确的是？
  1. 默认端口是 5060
  2. 信令和媒体走不同端口（带外）
  3. 媒体流要经过 SIP 代理转发
  4. SIP 消息可以走 TCP 或 UDP
代理只转信令，媒体直接在两端之间走。

题型 6　无线链路：组成、dB、SNR / BER、隐藏终端 ★★

组成与分类

  • 无线主机（无线 ≠ 移动）、基站（在有线网和覆盖范围内的无线主机之间中继，如蜂窝基站、802.11 AP）、无线链路（多路访问协议协调）。
  • 基础设施模式：经基站接入，换基站叫切换（handoff）；ad hoc：没有基站，节点自己组网。
单跳多跳
有基础设施WiFi、蜂窝mesh
无基础设施蓝牙、ad hocMANET、VANET

无线链路比有线难：信号衰减（路径损耗）、其他源干扰（2.4 GHz 和微波炉共用）、多径传播（反射后在不同时间到达）。

分贝

$$\text{dB} = 10\log_{10}\frac{P_S}{P_N}\qquad 10\to10\text{ dB},\ 100\to20,\ 1000\to30,\ 2\to\approx3$$

SNR 与 BER

  • 同一调制：加大功率 → SNR 升高 → BER 降低。
  • 不同调制：速率越高 → 同一 SNR 下 BER 越高（BPSK 1 Mbps < QAM16 4 Mbps < QAM256 8 Mbps）。
  • 给定 SNR 和 BER 要求：选满足 BER 要求的最快调制。讲义：SNR 15 dB、BER ≤ 10⁻³ → QAM16。这就是 W11 的速率自适应。

隐藏终端

A — B — C：A、B 互相听到，B、C 互相听到，A、C 听不到对方（障碍物或信号衰减）。A、C 都以为信道空闲，同时发 → 在 B 处碰撞，A、C 都不知道。W11 用 RTS / CTS 解决。

SNR = 15 dB，要求 BER ≤ 10⁻³，讲义图里应选哪种调制？
  1. BPSK
  2. QAM16
  3. QAM256
  4. 都不满足
QAM256 此时 BER 太高；BPSK 满足但只有 1 Mbps；QAM16 满足且最快。

题型 7　四节点无线中继（Tutorial） ★★

A — B — C — D 排一行，同一频率。A 只被 B 听到，B 被 A、C 听到，C 被 B、D 听到，D 只被 C 听到。节点每时隙可以发或收一条；同时听到 ≥ 2 个发送者就碰撞；不能同时发和收。

关键：看接收者同时听到几个发送者
问题无线有线为什么
C → A（经 B）1 条 / 2 时隙1 条 / 时隙B 发给 A 时不能同时收 C 的下一条
A → B 和 D → C2 条 / 时隙2 条 / 时隙B 只听到 A，C 只听到 D
A → B 和 C → D1 条 / 时隙2 条 / 时隙C 发时 B 也听得到，在 B 处碰撞

每条数据都要 ACK（占一个时隙）时（官方答案）：C → A 为 1 条 / 4 时隙；A → B + D → C 为 2 条 / 3 时隙；A → B + C → D 为 2 条 / 3 时隙。第 2 行官方答案偏保守（两个 ACK 同时发其实不碰撞），选择题按官方答。

上面的拓扑，A → B 和 C → D 同时进行（无线、无 ACK），每个时隙最多成功送达几条消息？
  1. 0.5
  2. 1
  3. 2
  4. 3
C 发时 B 也听到，两者同时发会在 B 处碰撞，只能轮流。

考前速记

  1. CDMA：编码 d × c，相加，解码内积 ÷ M；先查正交，不正交 n/a。
  2. WFQ $R w_i/\sum w_j$，只对有数据的类求和；权重相等 = 轮询；优先级非抢占，例子顺序 1、3、2、4、5。
  3. 令牌桶 $\le rt + b$；QoS 四原则：标记、隔离（监管）、高效、准入。
  4. DiffServ：边缘每流标记，核心每类转发；符合绿、超出红。
  5. SIP：5060，TCP / UDP，带外；REGISTER；代理 ≈ 本地 DNS；媒体不经代理；606 Not Acceptable。
  6. dB = 10 log₁₀；同调制加功率 BER 降；选满足 BER 的最快调制（15 dB → QAM16）。
  7. 隐藏终端：A、C 在 B 处碰撞；中继题看接收者听到几个发送者。
