题型 1　描述 → 哪一层 ★★★

为什么要分层

从「手机上点一下」到「光纤里的光脉冲」，中间要做的事太多。分层把大问题拆成小问题：每层只用下一层的服务，只给上一层提供服务。好处是每层可以单独换：把 Wi-Fi 换成以太网（换下面两层），浏览器完全不用改。越往下越具体（电压、光），越往上越抽象（用户看到的服务）。

五层协议栈

层回答的问题数据单元典型协议
Application怎样提供网络应用messageHTTP、SMTP、DNS、FTP、P2P、SIP、RTP
Transport不同设备上程序之间的端到端传输segmentTCP、UDP、MPTCP

每层再多一点

  • Link 的三件事：① 比特错误检测（发 010101 收到 010100 要能发现）；② 介质访问控制 MAC（两台设备同时发怎么办，本周博弈论就是这个问题）；③ 链路层寻址（确认这一帧是发给我的）。
  • Network：路由 + 转发，核心是怎么构造路由表。
  • Transport：一台机器跑很多程序，transport 把数据交给正确的那个进程；进程通过 socket 收发。TCP 可靠，UDP 不可靠。
陷阱
  • Network 是主机到主机，Transport 是进程到进程。选项常把两者互换。
  • 「端到端可靠传输」是 Transport（TCP），不是 Link 的功能。
「把数据报从源主机送到目的主机」对应哪一层？
  1. 链路层
  2. 传输层
  3. 网络层
  4. 应用层
datagram + host to host → 网络层。传输层是段、进程到进程。

题型 2　纯策略纳什均衡 ★★★

问题

两个用户用同一个无线信道发给 AP。一个发、一个不发：发的人成功。两人同时发：碰撞，谁都不成功，还白耗电。没有中央调度者，用户各自决定，而且都自私：自己能多得就一定换做法。博弈论分析他们最后停在哪里。

讲义收益表，格子里是（用户 1，用户 2）：

用户 1 发用户 1 不发
用户 2 发(−5, −5)(0, 10)
用户 2 不发(10, 0)(0, 0)

纳什均衡的定义

一个策略组合，任何一方单方面改变自己的策略都得不到好处。「单方面」= 只有自己改，对方不变。

解法：每个格子问两次
  1. 用户 1 换个做法（用户 2 不变），自己的收益变大吗？
  2. 用户 2 换个做法（用户 1 不变），自己的收益变大吗？
  3. 两次都「不会」，这一格才是纳什均衡。
格子均衡？理由
都发 (−5, −5)否任一方改不发：−5 → 0
1 发 2 不发 (10, 0)是1 改不发 10 → 0；2 改发 0 → −5，都更差
1 不发 2 发 (0, 10)是对称
都不发 (0, 0)否任一方改发：0 → 10

两个纯策略均衡都要求「一个人永远不发」，对被牺牲的人不公平，对等的设备也没法商量谁牺牲，所以要用混合策略。

囚徒困境：均衡 ≠ 最好

两人分开关押。都坦白各判 5 年；都沉默各判 1 年；一个坦白一个沉默，坦白的放走、沉默的判 10 年。收益用负刑期：

(A, B)A 坦白A 沉默
B 坦白(−5, −5)(−10, 0)
B 沉默(0, −10)(−1, −1)
  • (坦白, 坦白)：任一方改沉默 −5 → −10，更差 → 纳什均衡。
  • (沉默, 沉默)：总刑期最短，但 A 改坦白 −1 → 0 更好 → 不是均衡。
陷阱

「纳什均衡一定是对双方整体最好的结果」是错的，囚徒困境就是反例。

收益：独占发送 +10，碰撞各 −5，不发 0。哪些是纯策略纳什均衡？
  1. 两人都发
  2. 用户 1 发、用户 2 不发
  3. 用户 1 不发、用户 2 发
  4. 两人都不发
都发时任一方改不发能 −5 → 0；都不发时任一方改发能 0 → 10，所以 A、D 都不是。

题型 3　混合策略均衡 ★★★

每人像掷一枚不均匀的硬币：用户 1 以概率 $p_1$ 发，用户 2 以 $p_2$ 发，两人独立。用户 1 的期望收益 = 每种情况的收益 × 概率之和（不发的情况收益为 0，直接省掉）：

$$U_1 = -5\,p_1p_2 + 10\,p_1(1-p_2) = p_1\,(10 - 15\,p_2)$$

关键一步是把 $p_1$ 提出来。括号 $(10 - 15p_2)$ 是斜率：

  • 斜率 > 0（$p_2 < 2/3$）：用户 1 一直发最好。
  • 斜率 < 0（$p_2 > 2/3$）：用户 1 不发最好。
  • 斜率 = 0（$p_2 = 2/3$）：$p_1$ 取多少 $U_1$ 都是 0，用户 1 没有理由改。

令斜率为 0 得 $p_2 = 2/3$，对称地 $p_1 = 2/3$。混合均衡 $p_1 = p_2 = 2/3$，收益 (0, 0)：自私的用户发得太多，好处全被碰撞吃掉。

$$\text{一般形式（成功 } v\text{，碰撞 } {-c}\text{）：}\quad U_1 = p_1\big[v - (v+c)\,p_2\big] \;\Rightarrow\; p^* = \frac{v}{v+c},\quad \text{均衡收益} = 0$$
解法步骤
  1. 写出 $U_1$（只写非零收益的情况），提出 $p_1$。
  2. 令括号为 0，解出的是 $p_2$（让用户 1 无所谓的对方概率）。
  3. 同样写 $U_2$，提出 $p_2$，解出 $p_1$。
  4. 均衡收益：把解代回，括号为 0，所以收益为 0（当「不发」收益为 0 时）。
最容易搞反：我的概率由对手的收益决定

令 $U_1$ 的系数为 0 解出来的是 $p_2$，不是 $p_1$。对称题看不出来，不对称题（Tutorial 1 Ex 2）一定会考。

例：只有 1 发得 +20、只有 2 发得 +12；碰撞时 1 得 −4、2 得 −6。
$U_1 = p_1(20 - 24p_2) \Rightarrow p_2 = 5/6$；$U_2 = p_2(12 - 18p_1) \Rightarrow p_1 = 2/3$。
均衡是 $(p_1, p_2) = (2/3, 5/6)$，答成 $(5/6, 2/3)$ 就是搞反了。

独占发送收益改成 +15，碰撞仍 −5，不发 0。对称混合均衡的发送概率和合作最优的发送概率分别是？
  1. 3/4，3/8
  2. 2/3，1/3
  3. 3/4，3/4
  4. 3/8，3/4
$p^* = 15/(15+5) = 3/4$；合作最优是它的一半，3/8（见题型 4）。

题型 4　合作最优 vs 自私均衡 ★★

如果两人合作，一起选同一个 $p$ 让收益最大。令 $p_1 = p_2 = p$：

$$U = p(10 - 15p) = 10p - 15p^2,\qquad \frac{dU}{dp} = 10 - 30p = 0 \Rightarrow p = \frac13$$

代回：$U = -5\cdot\frac19 + 10\cdot\frac13\cdot\frac23 = -\frac59 + \frac{20}9 = \frac53$。

$$\text{一般形式：}\quad p^{\text{opt}} = \frac{v}{2(v+c)} = \frac{p^*}{2},\qquad U^{\text{opt}} = \frac{v^2}{4(v+c)}$$
发送概率每人收益
自私（纳什均衡）2/30
合作（最优）1/35/3

结论：自私导致发得太多、碰撞太多。少发一点、随机地发，双方都赚。Wi-Fi 的 CSMA/CA 随机退避就是这个思路（W10–W11）。

陷阱

问「混合纳什均衡」时，选项会放合作最优的 (1/3, 5/3)。均衡收益是 0，不是 5/3。

不对称收益：只有 1 发得 +20，只有 2 发得 +12，碰撞时 1 得 −4、2 得 −6。三个均衡（1 发 2 不发、1 不发 2 发、混合）中，两人收益之和最大的是？
  1. 用户 1 发、用户 2 不发
  2. 用户 1 不发、用户 2 发
  3. 混合策略纳什均衡
  4. 三者的总收益相同
总收益分别是 20、12、0。

题型 5　协议归层与 OSI ★

  • ISO/OSI 七层：application、presentation、session、transport、network、link、physical。本课把 presentation 和 session 并入应用层，剩五层。有的教材是四层（连 physical 也省），本课保留 physical。做题按五层答。
  • QUIC 一般算应用层（跑在 UDP 上），但因为它做可靠传输和拥塞控制，有时也被当成传输层（W12）。
  • 多媒体和无线是跨层主题，不只属于某一层。
  • 常见归层：DNS、HTTP、SMTP、FTP、SIP、RTP → 应用层；TCP、UDP → 传输层；IP → 网络层；以太网、Wi-Fi → 链路层。
下列协议与层的对应，正确的是？
  1. DNS — 应用层
  2. UDP — 传输层
  3. HTTP — 传输层
  4. SMTP — 应用层
HTTP 是应用层协议，它跑在 TCP（传输层）之上。

考前速记

  1. Link 相邻 / frame；Network 主机到主机 / datagram；Transport 进程到进程 / segment；Physical bits。
  2. Link 三件事：错误检测、介质访问控制、链路层寻址。
  3. 纳什均衡：任何一方单方面改都没好处；2×2 表逐格问两次。
  4. 混合均衡：$U_1 = p_1[v - (v+c)p_2]$，令系数为 0 解出对方的概率；$p^* = v/(v+c)$，收益 0。
  5. 合作最优 $p = v/(2(v+c))$，是均衡的一半；讲义例 1/3、收益 5/3。
  6. 囚徒困境：(坦白, 坦白) 是均衡，(沉默, 沉默) 最好但不是均衡。
  7. OSI 的 presentation、session 并入应用层；QUIC 归层有争议；多媒体、无线跨层。
