题型 2　CSMA/CA 流程 ★★★

为什么不能用有线的 CSMA/CD

CSMA/CD 边发边听、发现碰撞立刻停。无线做不到：

  • 自己的信号太强，发送时听不到别人；
  • 衰落，收到的信号太弱；
  • 隐藏终端，根本感知不到所有碰撞。

所以 802.11 不检测碰撞，而是避免碰撞（Collision Avoidance）。一旦碰撞，整个帧白发。

CSMA/CA 流程（必考）
  1. 发送方听到信道空闲达 DIFS，发整个帧（不做碰撞检测）。
  2. 信道忙：选随机退避值，定时器只在信道空闲时倒数，忙时冻结；到 0 就发。
  3. 没收到 ACK：扩大退避范围，回到第 2 步。
  4. 接收方正确收到后等 SIFS 回 ACK。
设计为什么
需要链路层 ACK发送方检测不到碰撞，只能靠 ACK 判断成功
SIFS < DIFS让 ACK 优先：其他想发数据的站要等更长的 DIFS
退避只在空闲时倒数公平：等得久的剩得少，下次更早发
失败后扩大退避降低再次碰撞的概率（同以太网指数退避）
和 CSMA/CD 的区别

CSMA/CD 听到空闲就立刻发，碰了再停；CSMA/CA 一开始听到忙，等空闲后还要再随机退避才发，因为碰撞的代价是整个帧。

关于 CSMA/CA，正确的是？
  1. 信道空闲 DIFS 后发送整个帧
  2. 退避定时器在信道忙时冻结
  3. 检测到碰撞就立即停止发送
  4. 没收到 ACK 时扩大退避范围
CSMA/CA 不检测碰撞，C 是 CSMA/CD。

题型 3　RTS / CTS，隐藏终端 vs 暴露终端 ★★★

思路：先用很短的帧预约信道，避免长数据帧碰撞。

  1. 发送方用 CSMA 向 AP 发短的 RTS。RTS 之间还会碰撞，但很短，损失小。
  2. AP 广播 CTS。
  3. 所有节点都听得到 CTS：发送方发数据，其他节点推迟。
  • RTS 碰撞了怎么知道？没收到 CTS。
  • 解决隐藏终端：C 听不到 A 的 RTS，但听得到 AP 的 CTS(A)，于是推迟。
  • 仍会失败：CTS 在某隐藏节点处被碰撞；或别的节点在 CTS 发出时正在发、没听到。结论：显著减少但不能完全消除碰撞，实际只对长帧启用。

暴露终端

S1 → R1，S2 → R2；S1、S2 相邻，但 R1 离 S2 远、R2 离 S1 远。两条本可同时进行，但 S2 听到 S1 在发就不发了。

隐藏终端暴露终端
问题该等没等（听不到干扰者）不该等却等了（听到无关的发送者）
后果碰撞吞吐量浪费
根源载波侦听在发送方做，碰撞发生在接收方

速率自适应

设备远离基站 → SNR 降、BER 升 → 切到更低速率、BER 更低的调制（QAM256 → QAM16 → BPSK）。是 W10「选满足 BER 的最快调制」的动态版。

S1、S2 相邻，S1 → R1、S2 → R2，两个接收方互不干扰，但 S2 听到 S1 在发就不发了。这叫？
  1. 隐藏终端
  2. 暴露终端
  3. 乒乓效应
  4. 三角路由
后果是吞吐量浪费，不是碰撞。

题型 4　蜂窝网络 2G / 3G / 4G ★★

  • 组成：cell（一块区域）、基站 BS（类似 AP）、空中接口（设备和基站之间的物理层 / 链路层协议）、MSC（连到电话网，管理呼叫建立和移动性）。
  • 第一跳共享频谱：FDMA / TDMA 组合，或 CDMA。
2G3G4G LTE
业务语音语音 + 数据全 IP
核心电路交换（BTS → BSC → MSC）语音网不变，并行一个数据网（SGSN → GGSN）EPC 统一电路和分组
空口FDMA / TDMACDMAOFDM + TDM

4G 两大创新：EPC（演进分组核心，全 IP）和 OFDM + 时分的无线接入。资源网格是频率 × 0.5 ms 时隙，基站可在任意时隙、任意频率给任意设备分配（W12 tutorial 在这个网格上分配）。

4G LTE 相对 3G 的两大创新是？
  1. 全 IP 的演进分组核心 EPC
  2. OFDM 结合时分复用的空口
  3. 语音网和数据网并行运行
  4. 用 CDMA 作为空中接口
C 是 3G 的特点，D 也是 3G。

题型 5　移动性：间接路由 vs 直接路由 ★★★

难点：手机号到哪都不变，但 IP 地址和子网绑定，换网就要换地址。

术语意思例子
归属网络移动设备永久的「家」128.119.40/24
永久地址归属网络里的地址，总能用它找到设备128.119.40.186
归属代理归属网络里替设备做移动性工作
访问网络设备当前所在的网络79.129.13/24
转交地址 COA访问网络里的地址79.129.13.2
外地代理访问网络里替设备做移动性工作
通信者想和移动设备通信的一方
  • 让路由器处理（路由表通告每台设备的永久地址）：扩展不到几百万台设备，不采用。
  • 注册：设备联系外地代理 → 外地代理告诉归属代理「它在我这」。
间接路由直接路由
步骤通信者发永久地址 → 归属代理截获转给外地代理 → 设备；设备直接回复通信者先向归属代理要 COA → 直接发外地代理 → 设备；设备直接回复
通信者用的地址永久地址转交地址
对通信者透明是否
路径三角路由（同一网络时尤其低效）接近最短
换访问网络向新 FA 注册，归属代理更新 COA，连接保持锚点外地代理：数据先到第一个 FA，再链式转给新 FA

讲义类比：找常搬家的朋友，翻遍电话簿（路由处理）、问她父母（间接）、等她告诉你住哪（直接）。

关于间接路由，正确的是？
  1. 存在三角路由问题
  2. 设备换网对通信者透明
  3. 通信者先向归属代理要 COA
  4. 移动设备直接回复通信者
C 是直接路由。

题型 6　Mobile IP（RFC 3344） ★★

三部分：间接路由、代理发现、向归属代理注册。

$$\underbrace{[\text{dst }79.129.13.2\ |\ \overbrace{[\text{dst }128.119.40.186\ |\ \text{数据}]}^{\text{原分组}}]}_{\text{归属代理 → 外地代理（封装）}}\ \xrightarrow{\text{外地代理解封装}}\ [\text{dst }128.119.40.186\ |\ \text{数据}]$$
  • 隧道：归属代理把原分组整个装进目的为 COA 的新分组（IP-in-IP）。
  • 代理发现：代理广播 ICMP type 9，扩展 type 16；R 位要求注册，H / F 位表示归属 / 外地代理，带若干 COA。
  • 注册例子：设备请求 Lifetime 9999、identification 714 → FA 转 HA → HA 回 Lifetime 4999、identification 714。归属代理可以缩短有效期；identification 请求和回复相同，用来配对、防重放。
Mobile IP 里归属代理怎么把分组送到移动设备？
  1. 直接改写原分组的目的地址
  2. 把原分组封装进目的为 COA 的新分组
  3. 在访问网络里广播这个分组
  4. 交给 DNS 解析出新地址再发
外地代理再解封装，交给设备。

题型 7　HLR / VLR、GSM 切换、切换算法 ★★

  • HLR（归属位置寄存器）：归属网络里的数据库，存号码、用户资料、当前位置。
  • VLR（访问位置寄存器）：访问网络里的数据库，当前在本网的每个用户一条。
  • 对应：HLR ≈ 归属代理，VLR ≈ 外地代理。
  • GSM 打给移动设备是间接路由：呼叫到归属网络 → 归属 MSC 查 HLR 得漫游号码（≈ COA）→ 建到访问 MSC 的第二段 → 接通设备。

GSM 同一 MSC 下的切换

为什么切：新 BSS 信号更强（保持连接、省电）、负载均衡。GSM 不规定何时切（策略）。由旧 BSS 发起。

  1. 旧 BSS 告诉 MSC 要切，给候选新 BSS 列表。
  2. MSC 建到新 BSS 的路径；新 BSS 分配无线信道；新 BSS 通知 MSC 和旧 BSS 已就绪。
  3. 旧 BSS 通知设备切过去；设备和新 BSS 激活信道；设备经新 BSS 告诉 MSC 完成，MSC 改路由。
  4. 释放 MSC 到旧 BSS 的资源。

先建新路，再让设备过去，最后拆旧路，所以不断线。

切换算法

算法条件特点
朴素 RSS$P_{new} > P_{old}$乒乓效应：边界附近来回切
阈值 $P_T$且 $P_{old} < P_T$旧的还够好就不切
迟滞 $P_H$$P_{new} > P_{old} + P_H$新的要明显更好，抑制乒乓
驻留定时器条件持续到定时器到期过滤短暂波动

记法：阈值看旧的够不够差，迟滞看新的好多少，驻留定时器看持续多久。

对上层的影响：TCP、UDP 照样跑，但TCP 把无线丢包当成拥塞，不必要地减小 cwnd；切换期间丢包和时延。

关于 GSM 同一 MSC 下的切换，正确的是？
  1. 由旧的 BSS 发起切换
  2. 先建新路径再让设备切过去
  3. 最后释放到旧 BSS 的资源
  4. 由 GSM 标准规定切换时机
GSM 不规定为什么、什么时候切。

  2. 把无线丢包当拥塞而减小 cwnd
  3. TCP 序号空间会溢出

  3. 无法保持正在进行的连接

A 和 C 都能和 AP 通信但互相听不到。A 发 RTS，AP 回 CTS(A)。C 此时也想发，C 会？
  1. 听不到 A，所以照常发送
  2. 听到 A 的 RTS 后推迟
  3. 听到 AP 的 CTS 后推迟
  4. 发 RTS 和 A 竞争信道
C 听不到 RTS 但听得到 CTS，这就是 RTS / CTS 解决隐藏终端的方式。

考前速记

  1. CSMA/CA：空闲 DIFS 就发；忙则退避，只在空闲时倒数；没 ACK 扩大退避；SIFS 回 ACK，SIFS < DIFS 让 ACK 优先。
  2. 不用 CSMA/CD：发时听不到、衰落、隐藏终端。
  3. RTS / CTS：短帧预约，CTS 人人听到；没 CTS = RTS 碰撞；减少但不消除碰撞。
  4. 隐藏终端 → 碰撞；暴露终端 → 浪费。
  5. 间接：永久地址、透明、三角路由；直接：COA、不透明、锚点 FA。
  6. Mobile IP：间接路由 + 代理发现（ICMP 9）+ 注册；隧道封装；有效期可被缩短。
  7. HLR ≈ 归属代理，VLR ≈ 外地代理；GSM 切换旧 BSS 发起，先建后拆。
  8. 阈值、迟滞、驻留定时器防乒乓；4G = EPC 全 IP + OFDM；3G 数据网并行。
  9. 被动扫描 3 步（AP 先），主动 4 步（主机先）；关联后 DHCP。
