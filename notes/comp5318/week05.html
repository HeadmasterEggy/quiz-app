题型 1　熵与信息增益手算 ★★★

$$H = -\sum_i p_i\log_2 p_i\qquad \text{Gain} = H(\text{父}) - \sum_{\text{子}}\frac{n_{\text{子}}}{n_{\text{父}}}H(\text{子})$$

计算器：$\log_2 x = \ln x / \ln 2$。$0\log 0$ 记 0。每一步选增益最大的特征；同一父节点上，加权子熵越小增益越大。

两类比例熵两类比例熵
1/2, 1/219/14, 5/140.940
3/4, 1/40.8112/5, 3/50.971
5/8, 3/80.954全同一类0
解法步骤
  1. 数父节点各类个数，算父熵。
  2. 按特征分组，每组算熵。
  3. 每组熵乘「组大小 / 父大小」，加起来。
  4. 父熵减去它。
例题（PE1 Q31）

父 4 正 4 负，$H = 1$。L 3 正 1 负，R 1 正 3 负，熵都是 0.811。

加权子熵 $= \frac48(0.811) + \frac48(0.811) = 0.811$；Gain = 0.189 bits。

例题（天气数据选根）

父 9 yes 5 no，0.940。outlook：sunny 2/3（0.971，5/14）、overcast 4/0（0，4/14）、rainy 3/2（0.971，5/14）。加权 0.693，Gain = 0.247；humidity 0.152，windy 0.048，temperature 0.029 → 根选 outlook。overcast 直接成叶子，sunny、rainy 各自只用自己那 5 天递归。

同一个父节点上，划分 X 的加权子熵比 Y 低，能得出什么？
  1. X 的信息增益更高
  2. Y 的信息增益更高
  3. X 的子节点更多
  4. 无法比较
父熵相同，减去的越小，增益越大。

题型 2　建树细节与剪枝 ★★

  • 数值特征：排序，在类别变化的相邻样本之间取中点作候选切分点（71 no、72 yes → 71.5），选增益最大的。
  • 增益偏爱取值多的特征：ID 编号把 14 天切成 14 组，每组熵 0，增益 0.940 最大但完全没用。修正：Gain ratio = Gain / SplitInfo，SplitInfo = 子组比例的熵（ID 为 $\log_2 14 = 3.807$；outlook 为 1.577，增益率 0.157）。
  • Gini：$1 - \sum p_i^2$，CART 用；纯为 0，各半为 0.5。
  • 预剪枝：max_depth、叶子最少样本数，可能停得太早。后剪枝（更常用）：长满后从下往上，换成叶子后验证集准确率不降就剪。
「ID 编号」特征的信息增益最大，但不该选它。用什么修正？
  1. 改用 Gini 指数
  2. 预剪枝限制深度
  3. 增益率（除以 SplitInfo）
  4. Laplace 平滑
SplitInfo 惩罚把数据切得很碎的特征。

题型 3　规则学习：1R 与 PRISM ★★

  • 决策树从根到叶子的路径是一条规则，条件之间是 AND：IF outlook = sunny AND humidity = high THEN no。
  • 1R：每个特征的每个取值预测多数类，数总错误；选错误最少的那一个特征。最终只用一个特征（天气数据 outlook 和 humidity 都错 4，平局任选）。
  • PRISM（覆盖算法）：一类一类生成规则；从空规则开始，每次加让正确比例最高的条件；还混着别的类就再加条件（覆盖更少但更纯）；纯了就移走覆盖的样本再生成下一条。
  • 决策树「分而治之」同时照顾所有类；覆盖算法一次只照顾一类。
只有 Colour = green 并且 Size = small 才到达 Yes 叶子。对应规则是？
  1. IF green OR small THEN Yes
  2. IF green AND small THEN Yes
  3. IF green THEN Yes
  4. IF NOT small THEN Yes
OR 会把不在这条路径上的样本也包进来。

题型 4　集成方法 ★★★

25 个独立分类器各自错 35%，多数投票错的概率约 6%。前提：每个比瞎猜好（二分类错误率 < 50%）；彼此不同（多样）。

方法最关键的操作组合训练
Bagging有放回抽样（bootstrap）得到不同训练集平等投票 / 平均并行
随机森林Bagging + 每次分裂只在随机一部分特征里选；树不剪枝多数投票并行
AdaBoost一个接一个，提高分错样本的相对权重按准确率加权投票串行
Gradient Boosting新树拟合残差 $y - \hat y$（平方损失的负梯度）预测相加串行
  • Bootstrap 中每个原样本至少被抽到一次的概率 ≈ $1 - e^{-1} = 63.2\%$。
  • Bagging 对不稳定模型（深树、神经网络）最有效；kNN 这种稳定的帮助不大。
  • 随机森林随机选特征是为了不让几个强特征让所有树长得一样。
  • Boosting 能把 decision stump 这种弱模型组合得很强，但不能并行、更容易拟合噪声。
AdaBoost 权重更新
  1. 算加权错误率 $e$。
  2. 分对的样本权重乘 $e/(1-e)$（< 1），分错的不变。
  3. 归一化（除以总和）。

4 个样本各 0.25，错 1 个：$e = 0.25$，分对的乘 1/3 → 0.0833；总和 0.5；归一化后分对 1/6、分错 1/2。

Bagging 最关键的训练数据操作是？
  1. 只用上一个模型分错的样本训练
  2. 每次分裂随机选一部分特征
  3. 让新模型拟合残差
  4. 在有放回抽样的 bootstrap 样本上分别训练
A 是 boosting 思路，B 是随机森林的额外随机化，C 是 GB。

计算练习

计算 · 自拟8 个样本 5 正 3 负。按 shape 划分：circle 3 正 0 负，square 2 正 2 负，triangle 0 正 1 负。求 Gain(shape)。

父熵 0.954。子熵：circle 0，square 1，triangle 0。

加权 $= \frac38(0) + \frac48(1) + \frac18(0) = 0.5$；Gain = 0.454。

计算 · 自拟AdaBoost：5 个样本权重各 0.2，第一个分类器分错 2 个。更新并归一化后各样本权重是多少？

$e = 0.4$。分对的 3 个乘 $0.4/0.6 = 2/3$ → 0.133；分错的 2 个 0.2。总和 0.8。

归一化：分对的各 1/6，分错的各 1/4。

计算 · 自拟父节点 6 正 2 负。划分 A：左 4 正 0 负，右 2 正 2 负。求 Gain(A)。

父熵 $H(3/4, 1/4) = 0.811$。左 0，右 1。加权 $= \frac48(0) + \frac48(1) = 0.5$。Gain = 0.311。

考前速记

  1. Gain = 父熵 − 加权子熵；常用熵 0.811、0.940、0.971、0.954。
  2. 增益偏爱多值特征 → 增益率；Gini $1 - \sum p^2$；后剪枝看验证集。
  3. 路径 = AND；1R 只用一个特征；PRISM 加条件让规则更纯。
  4. Bagging 有放回抽样（63.2%）；RF 再随机选特征；AdaBoost 分对乘 $e/(1-e)$ 再归一化；GB 拟合 $y - \hat y$。
  5. 集成前提：比瞎猜好 + 多样；Bagging/RF 可并行，Boosting 串行。
