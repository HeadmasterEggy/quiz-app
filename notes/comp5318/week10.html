题型 2　同一张表做 single 和 complete ★★★

步骤
  1. 当前表里找最小值，合并，记高度。
  2. 新簇到其他簇：single 取原始跨簇点对的 min，complete 取 max（可以用上一步表里的数递推；average 不行，要按点对数加权）。
  3. 划掉旧行列、写新行列，回到 1。
步Single linkComplete link
1{A, E}，高度 1{A, E}，高度 1
2{A, E, B}，高度 2{B, C}，高度 3
3{A, B, C, E}，高度 3{B, C, D}，高度 5
4全部，高度 4全部，高度 10

Single link 的树像一条链，每次多加一个点，最后一个大簇加零散点；complete link 先各自形成小簇，簇更紧凑、大小更平均。

常见错法

complete link 第 2 步：{A,E}–B 更新成 max(2, 6) = 6，不再是最小值，所以下一个合并是 B–C = 3，而不是 {A,E}–B。

用上表做 complete link，第一次合并 {A, E} 后，{A, E} 到 B 的距离是？
  1. 2
  2. 6
  3. 4
  4. 8
max(d(A,B), d(E,B)) = max(2, 6)。

混合练习

用上表，complete link 最后剩下的两个大簇是？
  1. {A, E} 和 {B, C, D}
  2. {A, B, C, E} 和 {D}
  3. {A, B} 和 {C, D, E}
  4. {A, E, B} 和 {C, D}
B 是 single link 的结果。
用上表做 single link，第二次合并的是？
  1. B 和 C，高度 3
  2. C 和 D，高度 5
  3. {A, E} 和 D，高度 8
  4. {A, E} 和 B，高度 2
{A,E}–B = min(2, 6) = 2 是最小。
为什么 average link 不能像 single / complete 那样直接用上一步表里的数递推？
  1. average 不是对称的
  2. average 只能用于一维数据
  3. 两个平均数不能直接再平均，要按点对数加权
  4. average 要用平方距离
min 和 max 可以嵌套，平均不行。

到 A / 到 D 的平方距离：A 0 / 74，B 4 / 58，C 10 / 32，D 74 / 0，E 106 / 4 → {A, B, C} 和 {D, E}。

新质心 $\mu_1 = (6/3, 6/3) = (2, 2)$，$\mu_2 = (9, 6)$。

第二轮：A 2 / 89，B 2 / 73，C 4 / 41，D 52 / 1，E 80 / 1 → 分配不变，收敛。

计算 · Tutorial T10 Ex.2用上表做 single link，写出每一步合并、高度和更新后的距离。

① {A, E}，1；{A,E}–B = 2，–C = 7，–D = 8。

② {A, E, B}，2；–C = min(7, 3) = 3，–D = min(8, 4) = 4。

③ C–D = 5 > 3，合并 {A, B, C, E}，3；–D = min(4, 5) = 4。

④ 全部，4。

考前速记

  1. 只有距离表时 K-means 只能分配。
  2. 每一步在更新后的表里重新找最小；single 用 min、complete 用 max，可以递推；average 要加权。
  3. 同一张表 single 和 complete 结果可能完全不同：single 链成大簇，complete 紧凑平均。
  4. 平局按题目规则（通常字母顺序）。
