题型 1　最小二乘手算 ★★★

直线 $\hat y = b_0 + b_1 x$。残差 $e_i = y_i - \hat y_i$（真实减预测）。让 SSE = $\sum e_i^2$ 最小的直线就是最小二乘直线。平方是为了正负不抵消，并重罚大误差。

$$b_1 = \frac{S_{xy}}{S_{xx}},\quad b_0 = \bar y - b_1\bar x,\qquad S_{xy} = \sum(x_i - \bar x)(y_i - \bar y),\quad S_{xx} = \sum(x_i - \bar x)^2$$

最小二乘直线一定经过 $(\bar x, \bar y)$。

解法步骤
  1. 算 $\bar x$、$\bar y$。
  2. 列表：$x - \bar x$、$y - \bar y$、两者乘积、$(x - \bar x)^2$；求和得 $S_{xy}$、$S_{xx}$。
  3. $b_1 = S_{xy}/S_{xx}$，$b_0 = \bar y - b_1\bar x$。
  4. 每个点算 $\hat y$、残差、残差平方；SSE 求和，MSE = SSE / n。

常见错法
  • 乘积里负负得正算错。
  • 新样本 $x = 2$ 恰好等于某训练点，也要报告模型预测值 3.0，不是训练集里的真实值 2。
  • MSE 忘了除以 n（SSE 才是总和）。
$\bar x = 3$，$\bar y = 7$，$S_{xy} = 10$，$S_{xx} = 5$。截距和 $x = 5$ 时的预测值是？
  1. 截距 7，预测 17
  2. 截距 2，预测 12
  3. 截距 1，预测 11
  4. 截距 −1，预测 9
$b_1 = 2$，$b_0 = 7 - 6 = 1$，$\hat y = 1 + 10 = 11$。

题型 2　误差指标与 R² ★★★

$$\text{MAE} = \frac1n\sum|y_i - \hat y_i|\qquad \text{MSE} = \frac1n\sum(y_i - \hat y_i)^2 = \frac{\text{SSE}}{n}\qquad \text{RMSE} = \sqrt{\text{MSE}}$$
  • MAE 随残差线性增长，MSE 随残差平方增长。想降低离群点影响用 MAE；想重罚大误差用 MSE / RMSE。
  • RMSE 单位和 y 一样，好解释。
$$\text{SST} = \text{SSR} + \text{SSE}\qquad R^2 = \frac{\text{SSR}}{\text{SST}} = 1 - \frac{\text{SSE}}{\text{SST}}$$

SST = $\sum(y - \bar y)^2$（只猜平均值的误差）；SSR = $\sum(\hat y - \bar y)^2$（直线解释掉的）；SSE（没解释的，训练误差）。$R^2 = 0.8$：y 的变化 80% 被 x 的直线关系解释。

正负号

$r = \pm\sqrt{R^2}$。$R^2 = 0.81$ 只能说 $r$ 是 0.9 或 −0.9，正负看斜率。

真实值 (2, 4, 8)，预测值 (1, 6, 7)。MAE 和 MSE 是？
  1. 1.33 和 2
  2. 2 和 1.33
  3. 1.33 和 6
  4. 4 和 6
残差 (1, −2, 1)：MAE $= 4/3$，MSE $= 6/3$。

题型 3　逻辑回归 ★★

线性回归做分类会输出 1.3、−0.2，不能当概率。逻辑回归先算 $z = b_0 + b_1 x$，再压进 (0, 1)：

$$p = \frac{1}{1 + e^{-z}}\qquad \ln\frac{p}{1-p} = b_0 + b_1 x$$
  • $p$ = 样本属于正类的估计概率；$z = 0$ 时 $p = 0.5$。阈值默认 0.5，高风险场景可调低。
  • 「线性」指对数几率（log-odds）是 x 的线性函数，不是 p。
  • 系数：线性回归最小化平方误差；逻辑回归最大化似然。
例题

$b_0 = -4.372$，$b_1 = 0.06696$，50 岁：$z = -4.372 + 3.348 = -1.024$；$p = 1/(1 + e^{1.024}) = 1/3.784 \approx 0.264$ → 类 0。

逻辑回归对某样本输出 0.83，阈值 0.5，怎么解释？
  1. 模型 83% 的预测是正确的
  2. 正类估计概率 0.83，判为正类
  3. 该样本一定属于正类
  4. 该样本与正类中心的距离是 0.83
只是估计，不保证正确。

题型 4　过拟合与正则化 ★★★

  • 过拟合：训练误差小、测试误差大（训练 RMSE 0.2，测试 8.5）；数据少、噪声多、模型太复杂。
  • 欠拟合：训练、测试都差。选验证集上最好的复杂度。
$$\text{Ridge (L2)}: J = \text{MSE} + \alpha\sum w_i^2\qquad \text{Lasso (L1)}: J = \text{MSE} + \alpha\sum|w_i|$$
L2 RidgeL1 Lasso
效果系数变小，一般不会正好为 0一部分系数正好为 0（稀疏）
额外用途—自动做特征选择

$\alpha$ 变大：惩罚重、系数小、模型简单；训练误差通常上升，测试误差可能下降；$\alpha$ 极大时斜率都 ≈ 0，预测平均值（欠拟合）；$\alpha = 0$ 就是普通线性回归。

别过度推论

正则化不保证测试精度一定提高；$\alpha$ 本身要用验证集或交叉验证来选。

用了 L1 惩罚后，好几个系数正好变成 0，这说明？
  1. 测试精度一定提高了
  2. 不再需要选惩罚强度
  3. 模型一定欠拟合了
  4. L1 惩罚能产生稀疏系数
L1 的典型效果；A、B 都是过度推论。

计算练习

计算 · 自拟数据 (0, 1)、(1, 3)、(2, 2)、(3, 6)。求最小二乘直线和训练 MSE。

$\bar x = 1.5$，$\bar y = 3$。$x - \bar x = (-1.5, -0.5, 0.5, 1.5)$，$y - \bar y = (-2, 0, -1, 3)$。

$S_{xy} = 3 + 0 - 0.5 + 4.5 = 7$；$S_{xx} = 2.25 + 0.25 + 0.25 + 2.25 = 5$。

$b_1 = 1.4$，$b_0 = 3 - 1.4\times1.5 = 0.9$，$\hat y = 0.9 + 1.4x$。

预测 (0.9, 2.3, 3.7, 5.1)，残差 (0.1, 0.7, −1.7, 0.9)，平方 (0.01, 0.49, 2.89, 0.81)，SSE = 4.2，MSE = 1.05。

计算 · 自拟用上面例题的逻辑回归系数，求 45 岁的人属于正类的概率。

$z = -4.372 + 0.06696\times45 = -4.372 + 3.013 = -1.359$。

$p = 1/(1 + e^{1.359}) = 1/(1 + 3.892) \approx 0.204$，判为类 0。

考前速记

  1. $b_1 = S_{xy}/S_{xx}$，$b_0 = \bar y - b_1\bar x$；直线过 $(\bar x, \bar y)$；MSE = SSE / n。
  2. MAE 对离群点不敏感；RMSE 单位同 y；SST = SSR + SSE，$R^2 = 1 - \text{SSE}/\text{SST}$，$r$ 的正负看斜率。
  3. 逻辑回归 $p = 1/(1 + e^{-z})$ 是正类概率；对数几率线性；最大似然。
  4. L1 产生正好为 0 的系数（特征选择）；L2 只压小；α 大 → 系数小 → 可能欠拟合；α 要用验证集选。
