题型 1　缩放与数据泄漏 ★★★

用距离的算法，数值范围大的特征会主导距离（收入以「元」计，年龄的差别几乎看不到）。缩放让各特征有同样的发言权，对每一列单独做。

$$\text{min-max：}\ x' = \frac{x - \min}{\max - \min}\qquad \text{标准化：}\ x' = \frac{x - \mu}{\sigma}$$

必须先缩放：kNN、k-means、SVM、PCA、神经网络。决策树不需要（只比大小）。

规则
  1. 缩放参数（min/max 或 μ/σ）只用训练集算。
  2. 用同一组参数缩放训练集和测试集。
  3. 交叉验证里，每一折只用这一折的训练部分拟合；用 pipeline 自动保证。
  4. 推广：填缺失值的均值、one-hot 的类别表等，凡是「从数据里算出来的」都只能来自训练集。
例题

训练集年龄最小 20、最大 60，测试样本 70 岁：$(70-20)/(60-20) = 1.25$。超出 [0, 1] 是正常的，不要改用测试集的最大值。

数据泄漏

用测试集、或「训练 + 测试」一起算参数，都是让模型偷看了将来的数据，测出的准确率偏高、不可信。先把整个数据集缩放好再切分做 CV 也是泄漏。

kNN 流水线用 standard scaler，要在保留测试集上评估，缩放参数应该？
  1. 用测试集算均值和标准差
  2. 用训练集算，同一组数缩放两边
  3. 用训练集 + 测试集一起算
  4. 每个测试样本各自标准化
A、C 都是泄漏；D 没有意义。

题型 2　手算距离与相似度 ★★★

$$\text{欧氏 } d = \sqrt{\textstyle\sum(a_i - b_i)^2}\qquad \text{曼哈顿 } d = \textstyle\sum|a_i - b_i|\qquad \text{Minkowski } q=1, 2$$

欧氏 ≤ 曼哈顿（两点之间直线最短）。$A = [1,3,5]$，$B = [1,6,9]$：差 0、3、4，欧氏 5，曼哈顿 7。

0/1 向量：先数四种情况

$$\text{SMC} = \frac{f_{11} + f_{00}}{f_{11} + f_{00} + f_{10} + f_{01}}\qquad \text{Jaccard} = \frac{f_{11}}{f_{11} + f_{10} + f_{01}}$$
  • 稀疏数据（购物篮）用 Jaccard：「两人都没买」太多，会把 SMC 撑高。
  • 0 和 1 同样有意义（医学阴 / 阳性）用 SMC。
$$\cos(A, B) = \frac{A\cdot B}{\lVert A\rVert\,\lVert B\rVert}\qquad \text{corr} = \frac{\text{cov}(x, y)}{\text{std}(x)\,\text{std}(y)}$$
  • 余弦适合文本（词频向量），和文章长短无关；常配 TF-IDF。
  • 相关系数为 0 只说明没有直线关系：$y = x^2$，$x$ 对称取值时 corr = 0。
  • 有序类别（cold / mild / hot）要先编成 0、1、2 再算差。
例题

$A = [1,1,0,1]$，$B = [1,0,0,1]$：$f_{11} = 2$，$f_{10} = 1$，$f_{01} = 0$，$f_{00} = 1$。SMC $= 3/4 = 0.75$；Jaccard $= 2/3 = 0.667$；余弦 $= 2/(\sqrt3\sqrt2) \approx 0.816$。

$x = (1, 4)$，$y = (4, 0)$，曼哈顿距离和欧氏距离分别是？
  1. 5 和 7
  2. 7 和 25
  3. 7 和 5
  4. 1 和 5
差 3 和 −4：$3 + 4 = 7$，$\sqrt{9 + 16} = 5$。

题型 3　kNN 与加权投票 ★★★

训练只存样本（lazy learner）；预测时算到每个训练样本的距离，取最近 $k$ 个投票（回归取平均）。

解法步骤
  1. 算新样本到每个训练样本的距离。
  2. 从近到远排序，取前 $k$ 个。
  3. 不加权：一个邻居一票。加权：每个邻居权重 $1/d^2$，各类加总，大者获胜。
例题（PE1 Q3）

邻居：Red（d = 2），Blue（d = 3），Blue（d = 4）。

不加权：Red 1 票，Blue 2 票 → Blue。

加权：Red $= 1/4 = 0.25$；Blue $= 1/9 + 1/16 = 0.111 + 0.0625 = 0.174$ → Red。

  • 预测慢：每个样本 $O(mn)$（$m$ 个训练样本、$n$ 个特征），还要存全部数据。加速：KD-tree、Ball tree。
  • $k$ 取奇数避免平票；经验 $k \approx \sqrt m$；$k = 1$ 对噪声敏感；$k = m$ 永远预测多数类。
  • 1-NN 的决策边界由 Voronoi 图构成。维度灾难：特征太多时距离都差不多。
别搞混

加权的对象是邻居，不是特征。

关于标准 kNN 分类器的预测，最合适的说法是？
  1. 预测很快，因为训练时建好了模型
  2. 预测时只需比较少数支持向量
  3. 预测时间与训练样本数无关
  4. 预测时要搜索所有存储样本，可用索引加速
基于实例的方法，代价都在预测时。

题型 4　其他预处理与特征选择 ★★

  • 缺失值：缺得少直接删；类别型填众数（有标签时用同类众数）；数值型用最像的几个样本的平均。
  • 噪声：数值被干扰、假样本（离群点）、不一致与重复。
  • 聚合：数据变小、更稳定，但丢细节。
  • 离散化：等宽、等频、k-means（都不看标签）。
  • One-hot：Single / Married / Divorced → 三位向量；编成 1、2、3 会让算法以为有大小和距离倍数。
特征选择做法速度
Brute force试所有 $2^n$ 种组合最慢
Embedded训练时顺便选（决策树）中等
Filter训练前用统计量打分，与算法无关最快
Wrapper用选定算法反复训练不同组合（前向选择 / 后向删除）慢

要删的特征：无关的（最喜欢的颜色）、冗余的（年收入元 / 千元 / 月收入）。

特征选择方法中，训练前用统计量打分、与后续算法无关、最快的是？
  1. Filter
  2. Wrapper
  3. Embedded
  4. Brute force
Wrapper 要反复训练；暴力要试 $2^n$ 种。

计算练习

计算 · 自拟训练样本：1 (1,3,1) yes，2 (3,5,2) yes，3 (3,2,2) no，4 (5,2,3) no。新样本 (2,4,2)。用欧氏距离，分别给出 1-NN、3-NN、3-NN 加权（$1/d^2$）的预测。

距离：到 1 为 $\sqrt3 \approx 1.73$；到 2 为 $\sqrt2 \approx 1.41$；到 3 为 $\sqrt5 \approx 2.24$；到 4 为 $\sqrt{14} \approx 3.74$。

排序：2 (yes)、1 (yes)、3 (no)。1-NN → yes；3-NN 2:1 → yes。

加权：yes $= 1/2 + 1/3 = 0.833$；no $= 1/5 = 0.2$ → yes。

计算 · 自拟三个最近邻：A 类 d = 1；B 类 d = 2、2、2（k = 4）。不加权和 $1/d^2$ 加权分别预测什么？

不加权：A 1 票，B 3 票 → B。

加权：A $= 1$；B $= 3\times\frac14 = 0.75$ → A。

考前速记

  1. 缩放参数只用训练集（CV 里只用这一折的训练部分）；测试值超出 [0,1] 正常。
  2. 欧氏 ≤ 曼哈顿；稀疏 0/1 用 Jaccard，0/1 对称有意义用 SMC；corr = 0 只是没有直线关系。
  3. 加权投票 $1/d^2$，加的是邻居的权；结论可能和不加权相反。
  4. kNN 是 lazy learner，预测 $O(mn)$；KD-tree / Ball tree 加速；$k$ 奇数、$\approx\sqrt m$。
  5. Filter 最快、Wrapper 慢、暴力最慢；one-hot 避免假顺序。
