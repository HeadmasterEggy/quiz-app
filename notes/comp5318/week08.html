题型 1　卷积与权重共享 ★★

全连接处理图像的问题：丢了空间结构、对位置敏感、参数太多（784 输入 × 32 = 25 120）。CNN 用小滤波器在图上滑动，对应位置相乘再相加得到特征图。

例题

滤波器 $\begin{bmatrix}1&0&1\\0&1&0\\1&0&1\end{bmatrix}$，图像块 $\begin{bmatrix}1&1&1\\0&1&1\\0&0&1\end{bmatrix}$：只有四角和中心起作用，$1 + 1 + 1 + 0 + 1 = 4$。

  • 图案越像，输出越大；滤波器的数是学出来的。
  • 权重共享：同一滤波器所有位置用同一组权重 → 参数少、图案出现在哪都能检测。
  • 多通道：滤波器厚度 = 输入通道数；各通道结果相加再加偏置，得一张特征图；K 个滤波器 → K 个输出通道。
一个学到的滤波器能在图像很多位置检测同一种边缘，且参数很少，靠的是？
  1. 滤波器权重在所有位置共享
  2. 最大池化
  3. 全连接输出层
  4. Dropout
权重共享。

题型 2　输出尺寸与参数个数 ★★★

$$\text{输出边长} = \left\lfloor\frac{n + 2p - f}{s}\right\rfloor + 1\qquad \text{参数} = K\times(f\times f\times C + 1)$$

$n$ 输入边长，$f$ 滤波器边长，$p$ 填充，$s$ 步长；$K$ 滤波器个数，$C$ 输入通道数，+1 是偏置。参数个数与图像宽高无关。池化也用同一个尺寸公式。

例子计算结果
7×7，3×3，s = 1$(7 - 3)/1 + 1$5×5
7×7，3×3，s = 2$(7 - 3)/2 + 1$3×3
7×7，3×3，s = 1，p = 1$(7 + 2 - 3)/1 + 1$7×7（同尺寸）
4 个 3×3，C = 2$4\times(18 + 1)$76
MNIST Conv2D(32, 3×3)$32\times(9 + 1)$320
再接 Conv2D(64, 3×3)$64\times(9\times32 + 1)$18 496
常见错法
  • 忘了偏置：$4\times18 = 72$；忘了通道：$4\times10 = 40$。
  • 第二层的 C 是上一层的滤波器个数（32），不是原图通道数 1。
4 个 3×3 滤波器，输入 2 个通道，每个滤波器有 1 个偏置。可训练参数共多少？
  1. 72
  2. 40
  3. 76
  4. 36
$4\times(3\times3\times2 + 1)$。

题型 3　池化与 CNN 结构 ★★

  • 最大池化取窗口最大值；平均池化取平均。2×2、步长 2：边长减半，面积减少 75%。
  • 池化没有可训练权重。作用：减少参数和计算、减少过拟合、对小偏移不敏感。
例题（PE2 Q22）

18×18 → 3×3 卷积（s = 1，p = 0）→ $(18 - 3) + 1 = 16$ → 2×2 池化（s = 2）→ $(16 - 2)/2 + 1 = 8$ → 8×8。

典型结构：输入 → [卷积 → ReLU → 池化] × 几次 → 拉平 → 全连接 → softmax。28×28×1 → 26×26×32 → 13×13×32 → 11×11×64 → 5×5×64 → 1600 → 10。前面的层学边缘，往后学纹理、部件。经典：LeNet-5、AlexNet（ReLU、dropout）、VGG（全 3×3、更深）、GoogLeNet（Inception，约 500 万参数）。

标准 2×2 最大池化从每个窗口传出什么？
  1. 四个值的平均
  2. 窗口里最大的值
  3. 学到的加权和
  4. 四个值的总和
池化没有要训练的权重。

题型 4　RNN 与 LSTM ★★

序列数据：长度不固定、前后有关系。RNN 一次读一个元素，维护隐藏状态（记忆）：

$$\mathbf h_t = \tanh(W_{hh}\mathbf h_{t-1} + W_{xh}\mathbf x_t)\qquad \mathbf y_t = W_{hy}\mathbf h_t$$
  • 每个时间步用同一组权重，能处理任意长度，参数不随长度增加。训练用 BPTT。
  • 例：$h_t = \tanh(0.5h_{t-1} + x_t)$，输入 (1, 0)：$h_1 = \tanh 1 = 0.762$，$h_2 = \tanh 0.381 = 0.364$（输入 0 但仍记得第 1 步）。
  • 形式：一对多（看图说话）、多对一（情感分类）、多对多（翻译、逐帧标注）。
  • 梯度消失 / 爆炸：反传每步乘一次 $W_{hh}$ 和 tanh 导数，难学远距离关系。

LSTM

加一条长期记忆 $C_t$，三个 sigmoid 门（0 全挡，1 全放）：

门作用
遗忘门 $f_t$旧记忆留多少
输入门 $i_t$ + 候选 $\tilde C_t$新信息写进多少
输出门 $o_t$记忆里哪些拿出来作为 $h_t$
$$C_t = f_t\odot C_{t-1} + i_t\odot\tilde C_t\qquad h_t = o_t\odot\tanh(C_t)$$

$C_t$ 的更新是加法，遗忘门 ≈ 1 时旧记忆和梯度几乎原样传过去 → 缓解梯度消失。措辞是「有助于」，不保证完美记忆。GRU 是简化版。

简单 RNN 中，把前面时间步的信息带到下一步的是？
  1. 每个位置一套独立权重
  2. 池化层
  3. 输出层的 softmax
  4. 循环的隐藏状态
循环权重在各时间步共享。

计算练习

计算 · 自拟64×64×3 输入 → Conv2D(8, 3×3, s = 1, p = 0) → 2×2 最大池化（s = 2）→ Conv2D(16, 3×3, s = 1, p = 1)。求每一步输出尺寸和两个卷积层的参数个数。

卷积 1：$(64 - 3) + 1 = 62$ → 62×62×8；参数 $8\times(27 + 1) = 224$。

池化：$(62 - 2)/2 + 1 = 31$ → 31×31×8；0 参数。

卷积 2：$(31 + 2 - 3) + 1 = 31$ → 31×31×16；参数 $16\times(9\times8 + 1) = 16\times73 = 1168$。

考前速记

  1. 输出边长 $\lfloor(n + 2p - f)/s\rfloor + 1$，卷积和池化连着算。
  2. 参数 $K(f^2C + 1)$；别忘偏置和通道；后一层的 C = 前一层的 K；与图像大小无关。
  3. 权重共享 → 参数少、位置无关；最大池化取最大、无参数。
  4. RNN：隐藏状态带信息、各步共享权重、BPTT、梯度消失。
  5. LSTM：遗忘 / 输入 / 输出门，$C_t$ 加法更新，有助于（不保证）长期记忆。
