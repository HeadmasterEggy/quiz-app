题型 1　线性 SVM 与间隔 ★★★

在两类之间修一条尽量宽的马路：中线是决策边界 $\mathbf w\cdot\mathbf x + b = 0$，两条边线 $\mathbf w\cdot\mathbf x + b = \pm1$，碰在边线上的点是支持向量。马路宽，留给新数据偏差的空间大。

$$\text{中线到一边} = \frac{1}{\lVert\mathbf w\rVert}\qquad \text{整个间隔} = \frac{2}{\lVert\mathbf w\rVert}\qquad \text{点到中线} = \frac{|\mathbf w\cdot\mathbf x + b|}{\lVert\mathbf w\rVert}$$
$$\min\ \tfrac12\lVert\mathbf w\rVert^2\quad\text{s.t. } y_i(\mathbf w\cdot\mathbf x_i + b) \ge 1\ \ \text{（硬间隔）}$$
  • 分类：$\mathbf w\cdot\mathbf x + b$ 正 → +1，负 → −1。
  • 解 $\mathbf w = \sum\alpha_i y_i\mathbf x_i$，只有支持向量的 $\alpha_i \ne 0$：删掉其他点重训，边界不变。
  • 数据只以点积形式出现 → 核技巧的基础。
例题

$\mathbf w = (3, 4)$，$\lVert\mathbf w\rVert = 5$：整个间隔 0.4，半条 0.2。$b = -10$，$\mathbf x = (2, 3)$：$6 + 12 - 10 = 8 > 0$ → +1，距中线 $8/5 = 1.6$。

常见错法

问「两个支持平面之间的距离」答 0.2：那是半条马路。

硬间隔 SVM，$\mathbf w = (3, 4)$。两个支持平面之间的距离是？
  1. 0.20
  2. 0.40
  3. 5.00
  4. 2.50
$2/5$。

题型 2　软间隔与 C ★★

数据有噪声、分不开，或者一个噪声点让马路被迫很窄。给每个点松弛变量 $\xi_i$：0 在马路外；(0, 1) 进了马路但仍在正确一侧；> 1 被分错。

$$\min\ \tfrac12\lVert\mathbf w\rVert^2 + C\sum_i\xi_i$$
C效果
大违例罚得重 → 马路窄、贴数据 → 易过拟合（有限的 C 仍允许少数违例）
小违例便宜 → 马路宽、模型简单 → 可能欠拟合
软间隔 SVM 把 C 调大，目标函数有什么变化？
  1. 对间隔违例的惩罚更重
  2. 间隔一定变宽
  3. 不再允许任何违例
  4. 核函数变得更平滑
只要 C 有限，仍允许一些违例。

题型 3　核技巧与代入 ★★★

一维 +类 {−3, −2, 2, 3}、−类 {−1, 0, 1} 分不开；加特征 $x^2$ 后一条水平线 $x^2 = 2.5$ 就分开，回到原空间边界是 $|x| = 1.58$（非线性）。

$$K(\mathbf u, \mathbf v) = \phi(\mathbf u)\cdot\phi(\mathbf v)$$

SVM 只用点积，所以不需要算（存）高维坐标，核函数直接在原空间给出点积。例：$\phi(x_1, x_2) = (x_1^2, \sqrt2x_1x_2, x_2^2)$，$\mathbf u = (1, 2)$，$\mathbf v = (3, 1)$：升维点积 $9 + 12 + 4 = 25$；核 $(\mathbf u\cdot\mathbf v)^2 = 5^2 = 25$。

核公式说明
线性$\mathbf x\cdot\mathbf y$先试它
多项式$(\mathbf x\cdot\mathbf y + 1)^p$p 大边界更弯
RBF$e^{-\gamma\lVert\mathbf x - \mathbf y\rVert^2}$sklearn 默认；无穷维
tanh$\tanh(\kappa\,\mathbf x\cdot\mathbf y + c)$只有部分参数满足 Mercer
  • RBF 的 $\gamma$ 大 → 每个点影响范围小 → 边界绕单个点 → 过拟合。
  • 训练 100%、测试差：减小 C 或减小 γ。
  • SVM 对数值大小敏感，训练前要缩放。
$\mathbf x = (1, 2)$，$\mathbf y = (3, 1)$，$K = (\mathbf x^T\mathbf y + 2)^2$。K 等于？
  1. 25
  2. 27
  3. 49
  4. 36
点积 5，$(5 + 2)^2$。

题型 4　PCA ★★★

身高、体重沿一条斜线分布：把坐标轴转到沿斜线方向，第二根轴方差很小可以丢掉，两个数变一个数。

  • 主成分两两正交；PC1 是方差最大的方向；每个 PC 是所有原始特征的线性组合。
  • PCA 无监督（不看标签）、线性。
  • PCA 不是挑列（那是特征选择），是转坐标系后保留前几个方向。
$$\text{前 }k\text{ 个累计比例} = \frac{\lambda_1 + \cdots + \lambda_k}{\sum_i\lambda_i}$$
例题（PE1 Q17）

方差 9、5、4、2，总和 20，要 ≥ 85%：前 1 个 45%，前 2 个 70%，前 3 个 90% → 3 个。

为什么先缩放

PCA 只看方差。收入以元计方差上亿，PC1 几乎就是收入方向，只因为单位让数字大；换单位主成分就变。先标准化；缩放参数和 PCA 都只在训练集上拟合。

  • SVD：$X = U\Sigma V^T$，$V$ 的列是主成分方向，奇异值平方 ∝ 方差，$U\Sigma$ 是新坐标。
  • 保留 k 个要存 $k(1 + n + m)$ 个数，压缩比 $k(1 + n + m)/(nm)$。
  • 用途：降维、提特征（人脸 1-NN 像素 27% → PCA 100 维 36%）、压缩、画图。
有同学说「PCA 就是挑出几列原始特征」。最准确的纠正是？
  1. PCA 挑的是方差最大的几列
  2. PCA 会用标签挑选特征
  3. PCA 是非线性变换
  4. PCA 是线性坐标变换，再保留部分新方向
每个新特征都混合了所有原始特征。

考前速记

  1. 间隔 $2/\lVert\mathbf w\rVert$，半条 $1/\lVert\mathbf w\rVert$；只有支持向量决定边界。
  2. C 大：违例罚重、易过拟合；C 小：马路宽、易欠拟合。
  3. 核：先点积 / 距离平方再套；只用点积所以不用存高维向量；过拟合减小 C、γ。
  4. PCA：正交、方差最大、线性组合、无监督；累计比例逐个加；先缩放；不是挑列。
