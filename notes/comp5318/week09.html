题型 1　K-means 一轮 ★★★

无监督：簇内近、簇间远。质心 = 坐标平均（不一定是真实点）；medoid = 到其他点距离和最小的真实点（类别数据用）。K-means 最小化

$$\text{SSE} = \sum_{\text{簇}}\sum_{\text{点}}\lVert\mathbf x - \boldsymbol\mu\rVert^2$$

平方距离下，让一组点距离平方和最小的位置正好是平均值（1、2、6：选 3 得 14，选 2 得 17）。

解法步骤
  1. 列每个点到每个质心的平方距离（不用开方，大小顺序不变）。
  2. 每个点分给最近的质心；用当前质心分配完所有点，中途不更新。
  3. 每个簇每个坐标分别求平均 → 新质心。
  4. 分配不变就收敛（SSE 单调不增，只保证局部最优）。
例题（PE1 Q33）

A(0,1)、B(2,1)、C(6,3)、D(8,3)，初始 $\mu_1 = A$，$\mu_2 = D$。

点到 μ₁到 μ₂分给
A0681
B4401
C4042
D6802

新质心 $\mu_1 = (1, 1)$，$\mu_2 = (7, 3)$；再分配不变，收敛。

  • 对初始化敏感：多跑几次取 SSE 最小（n_init）；K-means++（被选概率 ∝ 到最近已选质心的距离平方）；二分 K-means（反复拆 SSE 最大的簇）。
  • 要事先给 k；对离群点敏感；只适合球形、大小密度相近的簇（硬分配，边界是垂直平分线）；可能出现空簇。复杂度 $O(nkid)$。

  1. 簇内各坐标的中位数
  2. 簇内各坐标的平均值
  3. 离原点最近的点
  4. 簇内任意一个真实点
质心。中位数是绝对距离下的最优。

题型 2　GMM 责任度 ★★

数据由 k 个正态分布混合生成，每个分量有均值 $\mu_j$、方差 $\sigma_j^2$、权重 $\pi_j$（和为 1）。

$$\gamma_j = \frac{\pi_j f_j(x)}{\sum_l\pi_l f_l(x)}$$
例题（PE1 Q25）

$\pi = (0.3, 0.7)$，$f_1 = 0.4$，$f_2 = 0.2$：分子 0.12、0.14，总和 0.26，$\gamma_1 = 0.462$。

别选 0.12（没归一化）或 0.538（分量 2）。

  • 两分量中心 0 和 4，$\sigma = 1$，权重各半：$x = 2$ 正好中间，责任度各 0.5（K-means 会硬分一边）。
  • EM：E 步算责任度（软分配）；M 步按责任度加权重估 $\mu, \sigma, \pi$。

题型 3　簇间距离 ★★★

列出所有跨簇点对（一个来自簇 1，一个来自簇 2）的距离，然后：

方法取特点
Single最小值能找细长簇，但容易被一串噪声「链」成一片
Complete最大值紧凑、大小均衡
Average平均值介于两者之间
Ward合并后 SSE 增量和 K-means 目标一致
例题（PE2 Q25）

A = {0, 2}，B = {6, 8}：跨簇距离 6、8、4、6。Single 4，complete 8，average 6。

一维簇 A = {0, 2}，B = {6, 8}，绝对距离。single-link 和 average-link 距离是？
  1. 4 和 6
  2. 6 和 4
  3. 4 和 8
  4. 2 和 6
最小 4，平均 24/4。

题型 4　层次聚类合并顺序 ★★★

凝聚式（自底向上）
  1. 每个点一簇，填两两距离表。
  2. 合并表中距离最小的两簇，记合并高度。
  3. 新簇到其他簇的距离：回到原始点对距离取 min（single）/ max（complete）。
  4. 在更新后的表里再找最小，直到只剩一簇。
例题（PE2 Q33）

A = 0，B = 3，C = 8，D = 10。距离：AB 3，AC 8，AD 10，BC 5，BD 7，CD 2。

Complete：先合并 {C, D}（2）；{C,D}–A = max(8, 10) = 10，{C,D}–B = max(5, 7) = 7；再合并 {A, B}（3）。

{A,B} 与 {C,D}：single = 5（B–C），complete = 10（A–D）。

  • 树状图：竖直高度 = 合并距离；不需要事先给簇数，在某个高度横切。上例在高度 4 切得两簇，在 2.5 切得 {A}、{B}、{C, D}。
  • 缺点：空间 $O(n^2)$、简单实现时间 $O(n^3)$；合并不能撤销；对噪声敏感。

计算练习

计算 · 自拟一维点 1、2、9、10、11，k = 2，初始质心 1 和 2。做 K-means 直到收敛。

第 1 轮：{1} 和 {2, 9, 10, 11}，新质心 1 和 8。

第 2 轮：2 到 1 距离 1、到 8 距离 6 → {1, 2} 和 {9, 10, 11}，新质心 1.5 和 10。

第 3 轮：分配不变，收敛。注意初始质心挤在一起，第 1 轮很不平衡。

计算 · 自拟一维点 A = 0，B = 1，C = 5，D = 7，E = 15。用 single link 给出完整的合并顺序和每次合并高度。

距离：AB 1，CD 2，BC 4，……，DE 8。

① {A, B} 高度 1；② {C, D} 高度 2；③ {A,B}–{C,D} single = min(5, 7, 4, 6) = 4，{C,D}–E = 8，{A,B}–E = 14 → 合并 {A,B,C,D} 高度 4；④ 与 E 的 single = min(15, 14, 10, 8) = 8，高度 8。

考前速记

  1. K-means：平方距离表 → 分配完 → 求平均 → 不变就停；局部最优；K-means++ 按距离平方选初始。
  2. 平方距离下最优代表点是平均值；K-means 偏好球形、对初始化和离群点敏感。
  3. GMM：$\gamma = \pi f/\sum\pi f$，软分配；EM = E 算责任度、M 重估参数。
  4. Single 最小、complete 最大、average 平均，都对所有跨簇点对；更新时回原始距离。
  5. 层次聚类不需要 k，在树状图上横切；$O(n^2)$ 空间。
