题型 1　前向传播大题 ★★★

$$n = \mathbf w\cdot\mathbf x + b,\quad a = f(n)\qquad \sigma(z) = \frac{1}{1 + e^{-z}}\qquad \text{ReLU}(z) = \max(0, z)$$
z−2−1012
σ(z)0.1190.2690.50.7310.881
解法步骤
  1. 每个隐藏单元算预激活 $u$（加权和 + 偏置）。
  2. ReLU：负数变 0，正数不变，得 $h$。
  3. 用 $h$ 算输出 $z$。
  4. $\sigma(z)$ = 类 1 的概率；≥ 0.5 判类 1。
  5. 追问「把某单元换成恒等激活」：只有原来被截成 0 的负值单元受影响。
例题（PE1 Q32）

$x_1 = 1$，$x_2 = 3$；$u_A = x_1 + x_2 - 3$，$u_B = 2x_1 - x_2$；$z = h_A + 2h_B$。

$u_A = 1$，$u_B = -1$；$h_A = 1$，$h_B = 0$；$z = 1$，$\sigma(1) = 0.731$ → 类 1。

B 换成恒等：$h_B = -1$，$z = -1$，$\sigma(-1) = 0.269$ → 类 0，分类翻转。

为什么要非线性激活：全是线性层，叠多少层还是一个线性函数，学不会 XOR。通用逼近定理只说明足够宽的网络存在，不保证训练能找到。

ReLU 单元的预激活是负数，它输出？
  1. 原来的负数
  2. 0.5
  3. 0
  4. −1
$\max(0, z)$。

题型 2　感知机更新 ★★★

阶跃激活：$n \ge 0$ 输出 1，否则 0。边界是一条直线。

$$e = t - a\qquad \mathbf w \leftarrow \mathbf w + \eta e\mathbf x\qquad b \leftarrow b + \eta e$$
情况e调整
该 1 输出 0+1w 加 ηx，b 加 η
该 0 输出 1−1w 减 ηx，b 减 η
正确0不变
例题（PE1 Q19）

$\mathbf w = (0.4, -0.2)$，$b = 0.1$，$\eta = 0.2$，$\mathbf x = (2, 1)$，$a = 1$，$t = 0$：$\eta e = -0.2$；$\mathbf w = (0.4, -0.2) - (0.4, 0.2) = (0, -0.4)$；$b = -0.1$。

常见错法

忘了更新偏置（把它看成输入恒为 1 的权重）；$n = 0$ 时输出 1；输入分量为 0 的那个权重不变。

  • 线性可分时感知机保证有限步收敛，但找到任意一条线就停（不像 SVM 找最宽）。
  • AND、OR、NAND 可以；XOR 不行，要多一层：XOR = AND(NAND, OR)。
$\mathbf w = (1, 1)$，$b = 0$，$\eta = 1$，输入 (0, 0)，目标 0。更新后是？
  1. w = (0, 0)，b = −1
  2. w = (1, 1)，b = −1
  3. w = (1, 1)，b = 0
  4. w = (0, 0)，b = 0
$n = 0 \ge 0$ 输出 1，$e = -1$；输入全 0，w 不变，只有 b 减 1。

题型 3　梯度下降与反向传播 ★★

$$\mathbf w \leftarrow \mathbf w - \eta\nabla L$$

PE2 Q19：$\mathbf w = (0.5, -1)$，梯度 $(3, -2)$，$\eta = 0.1$：$(0.5 - 0.3, -1 + 0.2) = (0.2, -0.8)$。可能陷入局部最小。

方式多久更新一次特点
全批量看完全部样本梯度准，每步慢
SGD每个样本快，很吵
Mini-batch每一小批折中；吵是因为只用抽到的一批估计梯度
$$\Delta w_{pq} = \eta\,\delta_q\,o_p\qquad \delta_{\text{输出}} = (t - o)\,o(1 - o)\qquad \delta_{\text{隐藏}} = o(1 - o)\sum_i w_{qi}\delta_i$$
例题

$x = 1 \xrightarrow{0.5}$ 隐藏 $\xrightarrow{0.5}$ 输出，sigmoid，$t = 1$，$\eta = 1$。

$o_h = \sigma(0.5) = 0.622$，$o = \sigma(0.311) = 0.577$。$\delta_o = 0.423\times0.577\times0.423 = 0.103$；$\delta_h = 0.622\times0.378\times(0.5\times0.103) = 0.0121$。

$\Delta w_2 = 0.103\times0.622 = 0.064$；$\Delta w_1 = 0.0121\times1 = 0.012$。

$\mathbf w = (0.5, -1.0)$，梯度 $(3, -2)$，学习率 0.1，走一步后是？
  1. (0.8, −1.2)
  2. (3.5, −3.0)
  3. (0.2, −1.2)
  4. (0.2, −0.8)
减去 $(0.3, -0.2)$。A 是加了梯度。

题型 4　训练技巧 ★★

  • Softmax $p_i = e^{o_i}/\sum e^{o_j}$；(0.3, 0.8, 0.2) → (0.28, 0.46, 0.26)；损失用交叉熵。
  • 学习率太小慢、太大振荡发散；可衰减；Momentum 带上一步方向减少振荡。
  • 不能全 0 初始化：同层神经元梯度相同、永远一样（对称性）；用小随机数（Xavier）。
  • 梯度消失：sigmoid 两头平，导数 $o(1-o) \approx 0$，每层乘一次；ReLU 正区导数为 1 缓解。
  • Dropout：训练时每次随机关掉一部分单元，网络不依赖固定组合 → 正则化；单元不永久删除；推理用完整网络（inverted dropout 训练时已缩放，推理不再缩放）。
  • 早停：验证集不再提升就停（用验证集不用测试集）。
用 dropout 训练好的网络，标准推理方式是？
  1. 用完整网络，缩放与训练约定一致
  2. 继续随机关掉一半单元
  3. 永久删除训练时关得最多的单元
  4. 多次随机关掉单元取最好的一次
Dropout 只在训练时使用。

mini-batch 梯度下降为什么比全批量更「吵」？
  1. 学习率更大
  2. 权重初始化不同
  3. 只用抽到的一小批估计梯度
  4. 用了不同的损失函数

标准 dropout 训练时为什么每次随机关掉不同的隐藏单元？
  1. 加快每一步的计算
  2. 永久压缩网络规模
  3. 让梯度变大
  4. 防止依赖固定的单元组合、减少过拟合
是一种正则化。
为什么不能把所有权重初始化为 0？
  1. 同层神经元梯度相同，永远学不出差别
  2. sigmoid 在 0 处没有定义
  3. 会导致梯度爆炸
  4. 偏置无法更新
对称性问题。

  2. 学习率太大，调小
  3. 梯度消失，换 ReLU
  4. 数据泄漏，重新切分
sigmoid 导数小，每层乘一次。

计算练习

计算 · PE2 Q34$x_1 = 2$，$x_2 = -1$；$u_A = x_1 + 2x_2 - 1$，$u_B = 2x_1 - x_2 - 2$，ReLU，$z = 3h_A + h_B - 1$。(a) 求 $u_A, u_B, h_A, h_B$；(b) 求 $z$、概率、类别；再只把 A 换成恒等激活。

(a) $u_A = 2 - 2 - 1 = -1$，$u_B = 4 + 1 - 2 = 3$；$h_A = 0$，$h_B = 3$。

(b) $z = 0 + 3 - 1 = 2$，$\sigma(2) = 0.881$ → 类 1。

A 换恒等：$h_A = -1$，$z = -3 + 3 - 1 = -1$，$\sigma(-1) = 0.269$ → 类 0。

计算 · 自拟sigmoid 输出神经元 $o = 0.474$，目标 1。求 $\delta$；前一个神经元输出 0.332，$\eta = 0.9$，这条连接的 $\Delta w$？

$\delta = 0.526\times0.474\times0.526 \approx 0.131$；$\Delta w = 0.9\times0.131\times0.332 \approx 0.039$。

考前速记

  1. 前向：$u$ → ReLU → $z$ → σ → ≥ 0.5 判 1；换恒等只影响原来为负的单元；σ(±1) = 0.731 / 0.269，σ(2) = 0.881。
  2. 感知机：$e = t - a$，w 加 $\eta e\mathbf x$，b 加 $\eta e$；XOR 要两层。
  3. 梯度下降减梯度；mini-batch 吵是因为样本子集估计梯度。
  4. $\Delta w = \eta\delta o_p$；输出 $\delta = (t-o)o(1-o)$。
  5. Dropout 是训练时正则化，推理用完整网络；不能全 0 初始化；ReLU 缓解梯度消失。
