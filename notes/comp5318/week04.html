题型 1　朴素贝叶斯手算 ★★★

$$P(c\mid\text{证据}) = \frac{P(\text{证据}\mid c)\,P(c)}{P(\text{证据})}\qquad\text{后验} = \frac{\text{似然}\times\text{先验}}{\text{证据}}$$

比大小时各类分母相同，可以只比分子。朴素假设：已知类别后各特征条件独立，于是联合似然拆成连乘：

$$\text{得分}(c) = P(c)\times P(\text{特征}_1\mid c)\times P(\text{特征}_2\mid c)\times\cdots$$

假设在现实中几乎不成立，但分类时只要大小顺序对，效果常常不错。

解法步骤
  1. 先验：每类占总数的比例。
  2. 每个特征：在该类里这个取值出现的次数 ÷ 该类总数。
  3. 每类把先验和所有条件概率乘起来得到得分。
  4. 得分大的就是预测；题目要后验时，每类得分 ÷ 所有得分之和。
例题（天气数据，14 天：yes 9，no 5）

今天 (sunny, cool, high, true)。

特征值yesno
sunny2/93/5
cool3/91/5
high3/94/5
true3/93/5

yes：$\frac9{14}\cdot\frac29\cdot\frac39\cdot\frac39\cdot\frac39 \approx 0.0053$；no：$\frac5{14}\cdot\frac35\cdot\frac15\cdot\frac45\cdot\frac35 \approx 0.0206$ → 预测 no。

后验：$P(\text{no}\mid\cdot) = 0.0206/0.0259 \approx 0.795$，$P(\text{yes}\mid\cdot) \approx 0.205$。

最容易错

得分不是概率，加起来不等于 1。题目要后验时一定要做归一化。

朴素贝叶斯对多个特征做了什么假设？
  1. 各特征服从正态分布
  2. 已知类别后各特征相互独立
  3. 各类别的先验相等
  4. 特征与类别相互独立
条件独立，所以联合概率等于各特征概率相乘。

题型 2　Laplace 平滑与细节 ★★

某个取值在某类里从没出现过，条件概率为 0，整个乘积为 0，这一类被一票否决。平滑：

$$P(\text{取值}\mid c) = \frac{\text{次数} + 1}{\text{该类总数} + \text{这个特征的取值个数}}$$
例题

outlook 有 3 种取值，yes 的 9 天中分别出现 0、4、5 次。平滑后 1/12、5/12、6/12，加起来仍是 1。

  • 分母加的是取值个数（这里 3），不是 1，也不是类别个数。
  • 缺失值：算得分时跳过这个特征；训练时只数有记录的。
  • 数值特征（Gaussian NB）：每类假设正态，用 $\mu$、$\sigma$ 算密度代替概率。
  • 优点：训练快、对个别错误不敏感。缺点：重复特征（摄氏 / 华氏温度）会被乘两次、信息被放大。
Laplace 平滑主要解决什么问题？
  1. 特征之间不独立
  2. 数值特征无法计数
  3. 没见过的取值让整类乘积变成 0
  4. 类别不平衡
平滑后它有一个小的非零概率。

题型 3　训练 / 验证 / 测试与交叉验证 ★★★

训练集上的分数过于乐观（可能只是记住了数据）。超参数（kNN 的 k、树的最大深度）要选，但不能用测试集选，否则等于偷看考题，最后报告的分数偏高。

数据用途
训练集让模型学习
验证集（或训练集上的 CV）比较超参数，选最好的
测试集最后只用一次，报告最终分数
网格搜索完整流程
  1. 测试集先锁起来。
  2. 每组超参数在训练集上做 10 折 CV（分层 stratified），取平均分。
  3. 选平均分最高的那组。
  4. 用它在整个训练集上重新训练一次（CV 每次只用了 90%）。
  5. 在测试集上评估一次。

例：k ∈ {1,3,5,11,13} × 距离 {欧氏, 曼哈顿} = 10 组，10 折 → 100 次训练（不算最后重训）。

  • Holdout：切一次，受运气影响。Repeated holdout：报告均值 ± 标准差（79% ± 0.8% 比 ± 11% 可信）。
  • Leave-one-out：折数 = 样本数，结果确定，但最慢。
要选决策树最大深度，同时给出可信的最终成绩，正确做法是？
  1. 用验证集或训练集 CV 选深度，测试集只评估一次
  2. 用测试集选深度，再报告测试集分数
  3. 用训练集准确率选深度
  4. 用训练 + 测试集合并后做 CV 选深度
B、D 都让测试集参与了选择。

题型 4　precision / recall / F1 ★★★

预测正预测负
真正TPFN（漏掉）
真负FP（冤枉）TN
$$\text{Precision} = \frac{TP}{TP + FP}\quad \text{Recall} = \frac{TP}{TP + FN}\quad F_1 = \frac{2PR}{P + R} = \frac{2TP}{2TP + FP + FN}$$
  • Precision：「我说是正的，准不准」；Recall：「真正的正类，找得全不全」。TN 不出现在这三个指标里。
  • 类别不平衡时准确率会骗人：1000 封里 10 封垃圾，永远说「不是」也有 99% 准确率，但 recall = 0。
  • 癌症筛查：漏诊代价大 → 要 recall 高；门禁：放进坏人（FP）代价大 → 要 precision 高。
例题（PE1 Q10）

TP 12，FP 4，FN 8，TN 26：P = 12/16 = 0.75；R = 12/20 = 0.60；F1 = 24/36 = 0.667；Accuracy = 38/50 = 0.76。

TP = 18，FN = 6，FP = 12。recall 和 F1 是？
  1. 0.6 和 0.667
  2. 0.75 和 0.6
  3. 0.6 和 0.75
  4. 0.75 和 0.667
R = 18/24；F1 = 36/(36 + 12 + 6) = 36/54。

关于朴素贝叶斯，正确的有？
  1. 训练只需扫描数据计数，很快
  2. 重复特征不会影响结果
  3. 得分直接就是后验概率
  4. 缺失的特征可以在计算中跳过
重复特征会被乘两次；得分要归一化才是后验。
Leave-one-out 交叉验证的特点是？
  1. 最快，只训练一次
  2. 结果受随机切分影响大
  3. 结果确定，但要训练很多次
  4. 只用一半数据训练
折数等于样本数。

考前速记

  1. NB 得分 = 先验 × 各条件概率；后验 = 得分 / 总和；朴素 = 已知类别条件独立。
  2. Laplace：(次数 + 1)/(类总数 + 取值个数)；缺失值跳过；重复特征被放大。
  3. 超参数用验证集 / 训练集 CV 选；选完在全训练集重训；测试集只用一次。
  4. P = TP/(TP+FP)，R = TP/(TP+FN)，F1 = 2TP/(2TP+FP+FN)；不平衡时别只看准确率。
