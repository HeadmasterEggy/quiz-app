题型 1　回报、折扣与期望动作价值 ★★★

没有正确答案，只有奖励（常常延迟）；动作会影响之后看到的数据。目标：最大化未来累积奖励的期望（奖励假设）。MDP = 状态、动作、奖励、转移概率、折扣 γ，满足马尔可夫性。

组成是什么
策略 $\pi$每个状态选什么动作
价值函数状态（或状态 + 动作）长远看有多好
模型对环境的预测；Q-learning 不需要
$$G_t = r_t + \gamma r_{t+1} + \gamma^2 r_{t+2} + \cdots\qquad Q^*(s, a) = E\big[r + \gamma\max_{a'}Q^*(s', a')\big]$$
  • $r = (1, 0, 2)$，$\gamma = 0.5$：$G_0 = 1 + 0 + 0.25\times2 = 1.5$。
  • 打折：远处更不确定；无限任务也有限。γ 小 = 短视，γ ≈ 1 = 看重长远。
  • $V^\pi(s)$：从 s 出发按 π 的期望回报；$Q^\pi(s, a)$：先做 a 再按 π。有了 Q，选 Q 最大的动作。
期望动作价值
  1. 每种结果算「奖励 + γ × 到达状态的价值」。
  2. 按每种结果的概率加权平均。

PE2 Q30：0.4 概率 (r = 2，V = 6)，0.6 概率 (r = 0，V = 2)，γ = 0.5：$0.4\times5 + 0.6\times1 = $ 2.6。

奖励和转移不变，只减小折扣因子，直接影响是？
  1. 环境的转移概率改变
  2. 远期奖励相对即时奖励的权重下降
  3. 即时奖励的权重下降
  4. 学习率自动变大
环境本身没有任何变化。

题型 2　Q-learning 更新一步 ★★★

$$Q(s, a) \leftarrow Q(s, a) + \alpha\Big[\underbrace{r + \gamma\max_{a'}Q(s', a')}_{\text{目标值}} - Q(s, a)\Big]$$
三步
  1. 目标值 $= r + \gamma\max Q(s', \cdot)$；下一状态是终点时目标值 = r。
  2. 误差（TD error）= 目标值 − 旧值。
  3. 新值 = 旧值 + α × 误差（α = 1 时新值就是目标值）。
例题（PE1 Q30）

$Q = 1$，$\alpha = 0.5$，$r = 2$，$\gamma = 0.8$，$\max Q' = 5$：目标 6，误差 5，新值 3.5。

终止：$Q = 4$，$r = 10$，$\alpha = 0.1$，「$\max Q' = 20$」是干扰项：$4 + 0.1\times6 = 4.6$。

常见错法

选 6.00（目标值本身，相当于 α = 1）；终止状态还加 γ max Q。

  • off-policy：用下一状态的最大 Q，不管实际下一步选了什么。
  • ε-greedy：概率 ε 随机探索，否则利用；ε 随训练减小。
  • Q 表只适合状态、动作都少且离散（Taxi-v3：25 × 5 × 4 = 500 状态，6 动作）。
非终止：$Q_{\text{旧}} = 1$，$\alpha = 0.5$，$r = 2$，$\gamma = 0.8$，$\max_{a'}Q(s', a') = 5$。新值？
  1. 6.00
  2. 2.50
  3. 3.50
  4. 5.00
$1 + 0.5\times(6 - 1)$。

题型 3　DQN 的两个技巧 ★★★

状态是像素时 Q 表存不下，没见过的画面也没有估计。用神经网络 $Q(s, a; w)$ 近似：参数共享，相似画面输出相似，能泛化。Atari：输入最近 4 帧，一次输出所有动作的 Q 值。

$$L = \Big(r + \gamma\max_{a'}Q(s', a'; \hat w) - Q(s, a; w)\Big)^2$$
问题对策
连续样本高度相关，梯度偏向同一方向经验回放：存 $(s, a, r, s')$，随机抽小批；还能重复利用
目标值用同一个网络算，靶子一直在动目标网络 $\hat w$：固定若干步再复制在线参数；在线网络照常更新
取 max 导致高估Double DQN：当前网络选动作，旧网络打分
重要经历抽得太少Prioritized replay：误差大的更常抽

AlphaGo：策略网络减少搜索宽度，价值网络减少搜索深度；AlphaZero 纯自我对弈，同一算法学会围棋、国际象棋、将棋。

DQN 从存储的转移中随机抽样，而不是只用最新的连续转移，主要减少的是？
  1. 相邻训练样本的时间相关性
  2. 目标值的变化速度
  3. Q 值的高估
  4. 探索的次数
B 是目标网络，C 是 Double DQN。

计算练习

计算 · 自拟同一格连续更新两次：初始 Q = 0，α = 0.5，γ = 0.9，两次都是 r = 1、下一状态最大 Q = 2。两次之后 Q 是多少？

目标值都是 $1 + 1.8 = 2.8$。第 1 次 $0 + 0.5\times2.8 = 1.4$；第 2 次 $1.4 + 0.5\times1.4 = 2.1$。每次往目标靠近一半。

计算 · 自拟状态 s 有两个动作。a₁：确定得 r = 1，到达价值 4 的状态。a₂：0.5 概率 r = 5、到达终点（价值 0）；0.5 概率 r = 0、到达价值 2 的状态。γ = 0.9，哪个动作更好？

a₁：$1 + 0.9\times4 = 4.6$。

a₂：$0.5\times(5 + 0) + 0.5\times(0 + 0.9\times2) = 2.5 + 0.9 = 3.4$。

选 a₁。

考前速记

  1. $G_t = \sum\gamma^k r_{t+k}$；γ 小 = 短视；减小 γ 只降低远期奖励的权重。
  2. 期望动作价值：每个结果 $r + \gamma V$ 再按概率加权。
  3. Q-learning：目标值 → 误差 → 旧 + α×误差；终点目标 = r；别把目标值当答案。
  4. DQN：共享参数近似 Q；经验回放 = 打破相关性；目标网络 = 稳定目标值；Double DQN = 防高估。
