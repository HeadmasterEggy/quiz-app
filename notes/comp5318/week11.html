题型 1　马尔可夫链路径概率 ★★

马尔可夫假设：下一个状态只取决于当前状态。模型 = 初始分布 + 转移矩阵（行是今天、列是明天，每行和为 1）。

$$P(s_1, s_2, \dots, s_T) = P(s_1)\prod_{t=2}^{T}P(s_t\mid s_{t-1})$$
例题

$P(\text{晴}) = 0.1$，晴→晴 0.8，晴→多云 0.1，多云→雨 0.2：$P(\text{晴, 晴, 多云, 雨}) = 0.1\times0.8\times0.1\times0.2 = 0.0016$。

PE1 Q27：从 A 出发两步后在 B：A→A→B $0.6\times0.4 = 0.24$，A→B→B $0.4\times0.7 = 0.28$，合计 0.52。

两状态链从 A 出发，A→A 0.6，A→B 0.4，B→A 0.3，B→B 0.7。恰好两步后在 B 的概率？
  1. 0.28
  2. 0.40
  3. 0.52
  4. 0.24
两条路径要加起来。

题型 2　HMM 三大问题 ★★★

状态看不见（天气），只看得到和它有关的观测（访客带不带伞）。模型 $\lambda = (E, A, A_0)$：初始分布 $A_0$、转移 $a_{jk}$、发射 $e_k(x)$。

问题已知 → 求算法
Evaluation模型 → 观测序列的概率 $P(X)$前向
Decoding模型 → 最可能的整条隐状态序列Viterbi
Learning只有观测 → 估计 $A, E, A_0$EM（Baum-Welch）
HMM 的转移和发射概率未知，要从观测序列估计，这是？
  1. 评估，用前向算法
  2. 学习，用 EM（Baum-Welch）
  3. 解码，用 Viterbi
  4. 聚类，用 K-means
参数未知 = learning。

题型 3　前向算法手算 ★★★

$P(X)$ 要对所有 $N^T$ 条隐状态路径求和；前向算法合并共同前缀，复杂度 $N^2T$。

$$f_k(i) = P(x_1..x_i,\ \text{第 } i \text{ 步在 } k)\quad\text{（联合概率，不是后验）}$$
$$f_k(1) = A_0(k)\,e_k(x_1)\qquad f_k(i) = e_k(x_i)\sum_j f_j(i-1)\,a_{jk}\qquad P(X) = \sum_k f_k(T)$$
例题（PE1 Q34）

观测 (x, y)。$\pi = (0.7, 0.3)$；$e_A = (0.6, 0.4)$，$e_B = (0.2, 0.8)$；A→A 0.8，A→B 0.2，B→A 0.3，B→B 0.7。

$f_1(A) = 0.7\times0.6 = 0.42$；$f_1(B) = 0.3\times0.2 = 0.06$。

$f_2(A) = 0.4\times(0.42\times0.8 + 0.06\times0.3) = 0.4\times0.354 = 0.1416$。

$f_2(B) = 0.8\times(0.42\times0.2 + 0.06\times0.7) = 0.8\times0.126 = 0.1008$。

$P(x, y) = 0.1416 + 0.1008 = $ 0.2424。

常见错法
  • 递推用的是到达状态 k 的转移 $a_{jk}$（矩阵那一列），别读成从 k 出发的那一行。
  • 发射概率在括号外只乘一次。
  • 中间结果多保留几位，最后再四舍五入。

题型 4　Viterbi 手算 ★★★

和前向只差一处：$\sum$ 换成 $\max$，并记下取到最大的前一状态（指针），最后从最大的 $V_k(T)$ 回溯。

$$V_k(1) = A_0(k)\,e_k(x_1)\qquad V_k(i) = e_k(x_i)\max_j V_j(i-1)\,a_{jk}$$
例题（PE2 Q27）

$V_1(A) = 0.3$，$V_1(B) = 0.2$；$P(B\mid A) = 0.4$，$P(B\mid B) = 0.7$；$e_B = 0.5$。

候选 $0.12$、$0.14$ → 取 0.14（指针 B）→ $V_2(B) = 0.070$。前向则是 $(0.12 + 0.14)\times0.5 = 0.13$。

同一 PE1 Q34 模型跑 Viterbi：$V_2(A) = 0.4\times0.336 = 0.1344$（指针 A），$V_2(B) = 0.8\times0.084 = 0.0672$（指针 A）→ 路径 A, A。

看整条路径

第 1 步分数最高的状态不一定在最佳路径上（下面雨伞题：第 1 步 S 最高，但答案是 F, R）。看清题目问「概率」还是「最可能序列」。

HMM 和观测序列都固定，Viterbi 算法解决的是？
  1. 找最可能的完整隐状态路径
  2. 求观测序列的总概率
  3. 估计转移和发射概率
  4. 求每一步各状态的后验
解码。B 是前向算法。

计算练习

计算 · Tutorial T11 雨伞题隐状态 S、R、F，$A_0 = (0.4, 0.3, 0.3)$。转移（行是今天，到 S、R、F）：S (0.8, 0.05, 0.15)，R (0.2, 0.6, 0.2)，F (0.2, 0.3, 0.5)。发射（NA 没带伞、U 带伞）：S (0.9, 0.1)，R (0.2, 0.8)，F (0.7, 0.3)。观测 NA、U，最可能的天气序列？

第 1 步（NA）：$V_1 = (0.36, 0.06, 0.21)$。

到 S：max(0.288, 0.012, 0.042) = 0.288（S）× 0.1 = 0.0288。

到 R：max(0.018, 0.036, 0.063) = 0.063（F）× 0.8 = 0.0504。

到 F：max(0.054, 0.012, 0.105) = 0.105（F）× 0.3 = 0.0315。

最大 $V_2(R) = 0.0504$，指针 F → Foggy, Rainy。晴转雨只有 0.05，所以第 1 步最高的 S 不在最佳路径上。

计算 · 自拟用雨伞题的模型，用前向算法求 $P(\text{NA}, \text{U})$。

$f_1 = (0.36, 0.06, 0.21)$。

$f_2(S) = 0.1\times(0.288 + 0.012 + 0.042) = 0.0342$；$f_2(R) = 0.8\times(0.018 + 0.036 + 0.063) = 0.0936$；$f_2(F) = 0.3\times(0.054 + 0.012 + 0.105) = 0.0513$。

$P = 0.0342 + 0.0936 + 0.0513 = 0.1791$。

考前速记

  1. 马尔可夫链：初始 × 转移连乘；n 步后在某状态 = 所有路径之和；行和为 1。
  2. 概率 → 前向；最可能整条序列 → Viterbi；参数 → EM（Baum-Welch）。
  3. 前向：$f_k(1) = A_0 e$；$f_k(i) = e_k\sum_j f_j a_{jk}$；$P = \sum_k f_k(T)$。
  4. Viterbi：同上把 Σ 换 max，记指针、回溯；看整条路径。
  5. 用到达 k 的那一列转移；发射乘一次。
