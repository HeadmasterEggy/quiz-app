题型 1　熵的编码含义（赛马） ★★

在最优编码方案下：$h(x)$ = 传达这个取值要用的比特数；$H(X)$ = 平均比特数。每个比特相当于问了一个是非问题。

例题（讲课）：4 匹马

马$p$$h$Huffman 码
A1/210
B1/4210
C1/83110
D1/83111
$$H = \tfrac12(1) + \tfrac14(2) + \tfrac18(3) + \tfrac18(3) = 1.75\ \text{bits} < 2\ \text{bits（等长码）}$$

原理：常见的结果用短码，罕见的用长码，罕见的本来就少发生，平均下来更省。

  • 前缀码：没有任何码是另一个码的前缀，所以不需要停止符也能唯一解码。Huffman 构造老师说不考，理解前缀码即可。
  • 最优比特数通常不是整数（比如 5.1 bits），分块编码（一次编多个符号）让平摊码长逼近熵。
  • 信息不等于意义：测出 2 bits，数字本身不告诉你这 2 bits 是什么。
4 匹马获胜概率 1/2、1/4、1/8、1/8，最优编码下平均每次要几个比特？
  1. 2.00
  2. 1.75
  3. 1.50
  4. 1.00
就是熵。2 bits 是等长编码。

题型 2　从数据估计熵 ★★

Plug-in 估计：把样本频率直接当概率。11 个样本里 5 个 0 → $\hat p(0) = 5/11$。

实现步骤（Item 5）
  1. 转成数组；用 np.unique 找出出现过的符号（字母表）。
  2. 数每个符号出现次数，除以样本总数得概率。
  3. 把概率表交给 entropy 函数。符号可以是任何对象（['A','A','B','B'] → 1 bit）。
有限样本偏差

公平硬币每次只抛 10 次，算出的熵 0.97、0.97、1.00、0.72……经验数据只是真实分布的一次抽样，熵的 plug-in 估计偏低（biased down）。样本越多越接近真值（1000 次时多数接近 1）。这是 W5–W7 估计器和显著性的伏笔。

用 10 次抛硬币的数据做 plug-in 估计，熵的估计值通常会？
  1. 正好等于 1 bit
  2. 系统性地高于 1 bit
  3. 不超过 1，常偏低
  4. 是负数
样本频率很少正好 50/50，而二值熵在 50/50 时最大。

题型 3　联合熵与条件熵（查表计算） ★★★

$$H(X,Y) = \sum_{x,y} p(x,y)\log_2\frac{1}{p(x,y)}\qquad H(X\mid Y) = \sum_{x,y} p(x,y)\log_2\frac{1}{p(x\mid y)} = H(X,Y) - H(Y)$$
  • 联合熵：把 $(x, y)$ 粘成一个符号；两个二值变量 → 字母表 {00, 01, 10, 11}。单独看一个变量时叫边际熵。
  • 条件熵：已知 $Y$ 后，$X$ 还剩多少平均惊讶。注意权重是联合概率 $p(x,y)$，对数里是条件概率 $p(x\mid y)$。
解法步骤（给联合概率表）
  1. 行列求和得边际 $p(x)$、$p(y)$。
  2. $H(X,Y)$：表里每格 $p\log_2(1/p)$ 相加。
  3. $H(Y)$：边际算熵。
  4. $H(X\mid Y) = H(X,Y) - H(Y)$（比按定义逐格算 $p(x\mid y)$ 快）。

题型 4　性质与链式法则 ★★★

性质什么时候取等 / 边界
$H(X,Y) \le H(X) + H(Y)$独立时取等（代入 $p(x,y) = p(x)p(y)$ 可证）
$H(X\mid Y) \le H(X)$独立时取等：知道 $Y$ 平均不会增加对 $X$ 的不确定性
$H(X\mid Y) = 0$⟺ $X$ 完全由 $Y$ 决定（$p(x\mid y) = 1$，$\log 1 = 0$）
$H(X,Y) \ge \max(H(X), H(Y))$联合不会比任何一个边际更确定
$$\text{链式法则（永远成立）：}\ H(X,Y) = H(X) + H(Y\mid X)\qquad H(X_1..X_N) = \sum_i H(X_i \mid X_1..X_{i-1})$$
  • 顺序无关，只要一路条件化。也适用于局部值 $h$。
  • 老师类比复式记账：$X$ 的那份已经记过，再记 $Y$ 时必须是「已知 $X$ 的 $Y$」，否则重复计数、高估。
  • 例：单词 information 的最后一个 n，在前面字母已知时几乎不加信息；q 之后的 u 几乎零惊讶。
  • 剪刀石头布：三种动作等概率 $H = \log_2 3 = 1.585$ bits；但若策略是依次循环，$H(\text{move}\mid\text{prev}) = 0$。

熵唯一性的三条公理（正式版）：连续性；等概率时字母表越大熵越大（单调）；独立变量的熵相加（grouping / 可加）。

$H(X,Y) = H(X) + H(Y)$ 什么时候成立？
  1. 总是成立
  2. 仅当 $X$、$Y$ 独立
  3. 仅当 $X = Y$
  4. 仅当都是二值变量
一般只有 $\le$。总是成立的是链式法则。

简答练习

简答 · 自拟用 $p(x,y) = p(x)p(y)$ 证明：独立时 $H(X,Y) = H(X) + H(Y)$。

$H(X,Y) = -\sum_{x,y} p(x)p(y)\left[\log_2 p(x) + \log_2 p(y)\right]$

$= -\sum_x p(x)\log_2 p(x)\sum_y p(y) - \sum_y p(y)\log_2 p(y)\sum_x p(x)$

两个 $\sum = 1$，所以 $= H(X) + H(Y)$。∎ 关键一步：对数把乘积拆成和。

简答 · 自拟联合分布 $p(0,0) = 0.5$，$p(0,1) = 0.1$，$p(1,0) = 0.1$，$p(1,1) = 0.3$。求 $H(X\mid Y)$，写出每一步。

边际：$p(y{=}0) = 0.6$，$p(y{=}1) = 0.4$。

$H(X,Y) = 0.5\log_2 2 + 2 \times 0.1\log_2 10 + 0.3\log_2(1/0.3) = 0.5 + 0.664 + 0.521 = 1.685$ bits。

$H(Y) = 0.6\log_2(1/0.6) + 0.4\log_2 2.5 = 0.442 + 0.529 = 0.971$ bits。

$H(X\mid Y) = 1.685 - 0.971 = 0.714$ bits。

考前速记

  1. 最优编码：$h$ = 这个值的码长，$H$ = 平均码长；赛马 (½, ¼, ⅛, ⅛) → 1.75 bits。
  2. 前缀码无停止符；分块编码逼近熵；信息不等于意义。
  3. Plug-in：频率当概率；样本少时熵偏低。
  4. $H(X\mid Y) = H(X,Y) - H(Y)$；权重 $p(x,y)$，对数里 $p(x\mid y)$。
  5. $H(X,Y) \le H(X) + H(Y)$，独立取等；$H(X\mid Y) \le H(X)$，独立取等；$H(X\mid Y) = 0$ ⟺ $X$ 由 $Y$ 决定。
  6. 链式法则永远成立、顺序无关；不条件化就重复计数。
