题型 1　TE 定义与写出表达式 ★★★

问题：已经考虑了目标自己的过去（存储），源的过去还能多帮多少预测目标的下一个值？

$$T_{Y\to X}(k) = I\big(Y_n; X_{n+1}\mid\mathbf X_n^{(k)}\big) = \Big\langle\log_2\frac{p(x_{n+1}\mid\mathbf x_n^{(k)}, y_n)}{p(x_{n+1}\mid\mathbf x_n^{(k)})}\Big\rangle$$

一般形式（源嵌入 $l$、延迟 $u$）：

$$T_{Y\to X}(k, l, u) = I\big(\mathbf Y_{n+1-u}^{(l)}; X_{n+1}\mid\mathbf X_n^{(k)}\big)$$
解法步骤：写 TE 表达式
  1. 谁是目标？它的下一个值放在 MI 第二个位置。
  2. 目标嵌入 $k$：条件里放 $X_{n-k+1}, \dots, X_n$（以 $X_n$ 结尾）。
  3. 源嵌入 $l$、延迟 $u$：第一个位置放源的 $l$ 个值，最后一个是 $Y_{n+1-u}$。
例题（样卷 Q17 模式）

Y → X 的 TE，源嵌入 1，目标嵌入 2，延迟 1：$I(Y_n; X_{n+1}\mid X_{n-1}, X_n)$。

常见错法

把条件写成源的过去、把目标过去写成 $X_{n+1}, X_n$（包括了要预测的值），或者条件里少了 $X_n$。

Y → X 的 TE，源嵌入 1、目标嵌入 2、延迟 1，正确的是？
  1. $I(X_n; Y_{n+1}\mid Y_{n-1}, Y_n)$
  2. $I(Y_n; X_{n+1}\mid Y_{n-1})$
  3. $I(Y_n; X_{n+1}\mid X_{n-1}, X_n)$
  4. $I(Y_n; X_{n+1}\mid X_n, X_{n+1})$
A 方向反了；B 条件于源；D 条件里包含了要预测的值。

题型 2　TE vs 滞后 MI、PID ★★★

$I(Y_n; X_{n+1}\mid\mathbf X_n^{(k)})$ 和 $I(Y_n; X_{n+1})$ 都有方向，但条件于目标过去让 TE 成为动态的量，关心的是状态转移 $\mathbf x_n^{(k)}\to x_{n+1}$。

条件化的作用（W04）在 TE 里的意义
去除冗余，减少 MI源与目标过去重复的信息算作存储，不算传递
引入协同，增加 MI源在目标过去的语境下才有信息量的部分算进传递（状态依赖）

PID（Williams & Beer，两源：目标过去 M、源 Y）：

$$\text{AIS} = \{M\}_{\text{独有}} + \{M\}\{Y\}_{\text{冗余}}\qquad \text{TE} = \{Y\}_{\text{独有}} + \{MY\}_{\text{协同}}$$
$$H(X_{n+1}) = \underbrace{I(\mathbf X_n^{(k)}; X_{n+1})}_{\text{AIS}} + \underbrace{I(Y_n; X_{n+1}\mid\mathbf X_n^{(k)})}_{\text{TE}} + H(X_{n+1}\mid\mathbf X_n^{(k)}, Y_n)$$
按 PID，源和目标过去之间的冗余信息被算作？
  1. 传递
  2. 存储
  3. 修改
  4. 两边各算一半
先考虑过去的建模顺序：冗余归存储，协同归传递。

题型 3　Heartbeat 局部 TE ★★

源 S 是两状态马尔可夫链（$\lambda_1 = p(1\mid0) = 0.05$，$\lambda_0 = p(0\mid1) = 0.2$），目标复制源的上一个值 $d_{n+1} = s_n$。于是 $p(d_{n+1}\mid d_n, s_n) = 1$：

$$t_{S\to D} = \log_2\frac{1}{p(d_{n+1}\mid d_n)}$$
事件局部 TE局部滞后 MI差异
0 → 1 切换$\log_2\frac1{0.05} = $ 4.322.32TE 大：协同
1 → 0 切换$\log_2\frac1{0.2} = 2.32$0.32TE 大：协同
保持 1$\log_2\frac1{0.8} = 0.32$2.32TE 小：冗余
保持 0$\log_2\frac1{0.95} = 0.074$0.32TE 小：冗余

  • 没有负的局部 TE：分子总是 1，源从不误导。
  • 平均 TE = 源过程的熵率（W09 的 0.374）：源每步的全部新信息都传给了目标。
  • MI 只看「目标现在是不是 1」，TE 看转移，这才符合「信息传递」的直觉。

CA rule 54：只用邻居作源（周期边界 (d-1) % 10000）、合并样本，k = 15，TE ≈ 0.08 bits；glider 处局部 TE 强正 = 传递实体。左邻 → 格子突出右行 glider。

题型 4　TE ≠ 因果；Gaussian TE = Granger ★★

  • 因果关心干预的效应（Pearl）；信息传递把动态建模为计算。
  • 例：X、Y 都是 0/1 交替且反相。无论 X 是被 Y 驱动还是自己翻转，观测数据一模一样；X 的过去已经完全预测下一个值，TE = 0，全是存储。
  • 因果源可能只服务于存储；非因果源（隐藏共同驱动）可以有传递 → 尽量只分析因果源（CA 只看邻居）。
  • TE 能看到因果度量看不到的涌现计算结构（切换、glider）。两个概念互补。
  • Gaussian 估计器的 TE 就是 Granger 因果（Granger = 2 × TE，TE 以 nats 计）。
关于 TE 与因果效应，正确的是？
  1. TE 显著就证明存在因果
  2. TE 为零就证明没有因果
  3. TE 只能在干预实验中计算
  4. 因果源可能只表现为存储
反相交替例子：Y 驱动 X，但 TE = 0。

题型 5　实践三步与条件 TE ★★★

实践三步
  1. 目标嵌入 $k, \tau_X$：和 AIS 一样（最大化偏差修正 AIS / Ragwitz），先嵌入目标，免得把存储算成传递。
  2. 源嵌入 $l, \tau_Y$：观测掩盖了隐马尔可夫过程，或者多个过去 Y 值有因果作用时才需要。
  3. 源-目标延迟 $u$：取使 TE 最大的，简单条件下与真实因果延迟一致（Wibral 2013）。JIDT 用 DELAY（kernel 估计器除外）。

JIDT KSG 的 AUTO_EMBED_METHOD：NONE、RAGWITZ、RAGWITZ_DEST_ONLY、MAX_CORR_AIS、MAX_CORR_AIS_DEST_ONLY（_DEST_ONLY 只嵌入目标）。

条件 TE

$$T_{Y\to X\mid Z} = I\big(Y_n; X_{n+1}\mid\mathbf X_n^{(k)}, Z_n\big)$$
结构成对 TE条件于 Z 后
共同驱动 Z→Y，Z→X虚假 Y→X冗余去掉，消失
路径 Y→Z→X间接 Y→X消失
门控 / XOR：Y、Z 共同决定 X≈ 0，看不出协同显现

信息回归：两个都需要

$$I(Y, Z; X_{n+1}\mid\mathbf X) = T_{Y\to X} + T_{Z\to X\mid Y} = T_{Z\to X} + T_{Y\to X\mid Z}$$

成对 TE 和条件 TE 是同一链式分解按不同顺序展开的项，相加等于集体 TE。哪个顺序都对（样卷 Q19）。

生理数据：心率 → 呼吸最优延迟 6（0.055 nats，显著）；条件于血氧后 CTE = 0.024 nats 仍显著，说明心率给了血氧给不了的信息，但部分冗余。

X = Y XOR Z（Y、Z 独立均匀）。成对 TE Y→X 和条件 TE Y→X|Z 分别大约是？
  1. 1 bit 和 0
  2. 0 和 1 bit
  3. 都是 0
  4. 都是 1 bit
门控 / 协同：单看 Y 没用，知道 Z 后 Y 决定 X。

简答练习

简答 · 自拟解释 TE 与滞后互信息 $I(Y_n; X_{n+1})$ 的区别，并说明为什么 TE 更符合「信息传递」的直觉（可用 heartbeat 例子）。

两者都有方向。TE 条件于目标过去 $\mathbf X_n^{(k)}$：去掉源与目标过去的冗余（那部分其实是存储），并加入源在目标过去语境下才有的协同信息。

Heartbeat：滞后 MI 平均 0.722 bits，只要目标是 1 就「有信息」（保持 1 也是 2.32 bits）；TE 平均 0.3735 bits，在切换时最大（0 → 1 为 4.32 bits），保持时很小。传递应该是过去预测不到、由源带来的新信息，所以 TE 更合适。

简答 · 自拟写出 Y→X 的 TE：源嵌入 $l = 2$（间隔 1）、目标嵌入 $k = 3$、源-目标延迟 $u = 2$。

$I(Y_{n-2}, Y_{n-1}; X_{n+1}\mid X_{n-2}, X_{n-1}, X_n)$。源最后一个值是 $Y_{n+1-u} = Y_{n-1}$。

考前速记

  1. $T_{Y\to X} = I(Y_n; X_{n+1}\mid\mathbf X_n^{(k)})$；目标过去以 $X_n$ 结尾；源最后一个值 $Y_{n+1-u}$。
  2. 条件化：冗余归存储，协同归传递；TE 关注状态转移。
  3. Heartbeat：局部 TE $= -\log_2 p(d_{n+1}\mid d_n)$，0→1 为 4.32 最大，无负值，平均 0.3735 = 源熵率。
  4. TE ≠ 因果；Gaussian TE = Granger / 2；尽量只分析因果源；glider = 传递实体。
  5. 三步：目标嵌入 → 源嵌入 → 延迟取 TE 最大；_DEST_ONLY 只嵌目标。
  6. 条件 TE：去共同驱动 / 路径，显现门控；成对 + 条件 = 集体 TE，两者都要。
