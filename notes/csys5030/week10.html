题型 1　AIS 定义与局部 AIS ★★★

问题：变量自己的过去，在多大程度上帮助预测它的下一个值？

$$A_X(k) = I\big(\mathbf X_n^{(k)}; X_{n+1}\big) = \Big\langle\log_2\frac{p(x_{n+1}\mid\mathbf x_n^{(k)})}{p(x_{n+1})}\Big\rangle\qquad A_X = \lim_{k\to\infty}A_X(k) = H(X) - H_{\mu X}$$
  • 局部 AIS $a_X(n+1) = \log_2\frac{p(x_{n+1}\mid\mathbf x_n^{(k)})}{p(x_{n+1})}$：某个具体过去对某个具体下一个值的信息。
  • 局部 AIS 为负：过去让实际发生的值显得更不可能，过去是误导性的，动态上是模式被打破（信息来自别处，如 glider 闯入 domain）。
  • 「Active」：只算正被用于计算下一个值的存储。
  • 捕获的存储包括：动态中的主动存储、内部因果存储、经反馈 / 前馈环路的分布式存储、输入驱动的存储。对观察者都表现为存储。
CA 中某处局部 AIS 为强负值，最可能的含义是？
  1. 这里是 blinker
  2. 原有模式被打破，信息来自别处
  3. 估计器出错了
  4. 这里没有任何信息
glider 经过的地方，过去的 domain 模式误导了预测。

题型 2　周期序列的最小 k 与手算 ★★★

序列k=1k=2k=3为什么
0101…1.001.001.00上一个值决定下一个
0011…≈ 01.001.000 之后可能是 0 或 1；00→1，01→1，11→0，10→0
0001…0.090.260.81要 3 个才能确定位置；$0.81 = H_b(1/4)$

最小 k = 使 $H(X_{n+1}\mid\mathbf X_n^{(k)}) = 0$ 的最小值（确定性周期序列时）。

例题：0001 的局部 AIS（k = 3）

  • 过去 000 → 下一个一定是 1：$a = \log_2\frac{1}{1/4} = 2$ bits（罕见事件被准确预测，信息大）。
  • 过去 001、010、100 → 下一个一定是 0：$a = \log_2\frac{1}{3/4} = 0.415$ bits。
  • 平均 $\frac14(2) + \frac34(0.415) = 0.811$ bits ✓。
周期为 4 的序列 0-0-1-1-0-0-1-1…，能捕获过去全部影响的最小历史长度 k 是？
  1. 0
  2. 1
  3. 2
  4. 4
k = 1 时「0 之后」可能是 0 或 1；k = 2 时完全确定。

题型 3　k 怎么选 ★★★

$\mathbf X_n^{(k,\tau)}$ 是 Takens 嵌入（可加延迟 τ）。目标：嵌入已包含全部相关过去，$p(x_{n+1}\mid\mathbf x_n^{(k)}, x_{n-k}) = p(x_{n+1}\mid\mathbf x_n^{(k)})$。

想要 k 大想要 k 小
捕获所有记忆维度升高，欠采样（状态配置数指数增长）

甜点：更早的值确实不再贡献，或者数据不够证实它们的贡献。

方法做法
Ragwitz用 K 近邻的平均 $x_{n+1}$ 做预测，最小化预测误差
最大化偏差修正 AIS$A' = A - \langle A^s\rangle$，加入的新值带来的信息增量 > 偏差增量就继续加；KSG 内置偏差修正，直接最大化 AIS
非均匀嵌入逐个挑仍有显著贡献的过去时间点；在 IDTxl，JIDT 没有

JIDT：AUTO_EMBED_METHOD ∈ {NONE, RAGWITZ, MAX_CORR_AIS}，配 AUTO_EMBED_K_SEARCH_MAX、AUTO_EMBED_TAU_SEARCH_MAX；结果写回 k_HISTORY、TAU。只对 KSG / Gaussian；Discrete 要手动扫 k。

用离散估计器扫 k，原始 AIS 随 k 单调上升。应该怎么选 k？
  1. 选原始 AIS 最大的 k
  2. 总是选 k = 1
  3. 选最大的可算 k
  4. 选偏差修正 AIS 最大的 k
原始 AIS 上升有一部分是偏差。

题型 5　AIS vs excess entropy vs 自相关 ★★

预测对象衡量
AIS只是下一个值正被用于计算下一个值的存储；和传递互补，本课主角
Predictive information $E_X = I(\mathbf X_n^{(k)}; \mathbf X_{n+1}^{(k+)})$整个未来全部存储（包括以后才用到的）
Excess entropy块熵渐近线的截距；平稳时 = predictive information
自相关下一个值只是每个过去值单独的线性分量；AIS 把过去当联合状态，含非线性

强而长的自相关意味着应预期显著的 AIS（样卷 Q18）。

简答练习

简答 · 自拟用离散估计器对一条长二值时间序列扫描 k = 1…20 的 AIS，原始值单调上升。你怎样选 k？k 很大时偏差修正 AIS 变成负数，怎么解释？

对每个 k 算偏差（surrogate 均值或解析零分布均值），取偏差修正 AIS $A - \langle A^s\rangle$ 最大的 k。

原始 AIS 上升一部分来自欠采样偏差：状态数 $2^k$ 指数增长，偏差约随之翻倍。修正值为负表示现有数据无法证实更早值的贡献，不是「没有影响」。

考前速记

  1. $A_X(k) = I(\mathbf X_n^{(k)}; X_{n+1})$，$A_X = H(X) - H_\mu$；局部负 = 模式被打破。
  2. 最小 k：0101 → 1，0011 → 2，0001 → 3；罕见事件被准确预测时局部值大。
  3. k 的选法：Ragwitz、最大化偏差修正 AIS（KSG 内置）、非均匀嵌入（IDTxl）；AUTO_EMBED_METHOD 只对 KSG / Gaussian。
  4. 同质变量合并样本；rule 54 k ≈ 15；blinker / domain = 存储，glider 处为负；英文 k = 3。
  5. 修正后为负 = 数据不足以证实。
  6. AIS 只管下一个值；excess entropy / predictive info 是全部存储；自相关只看线性。
