题型 1　CMI 定义与证明 ★★★

$$I(X;Y\mid Z) = H(X\mid Z) + H(Y\mid Z) - H(X,Y\mid Z) = H(X\mid Z) - H(X\mid Y,Z)$$
  • 和 MI 完全平行，每一项都加上「已知 $Z$」。读法：已知 $Z$ 后，再知道 $Y$ 能额外消除多少关于 $X$ 的不确定性。
  • 推导：先固定 $z$ 算 MI，再按 $p(z)$ 平均；$p(z)p(x,y\mid z) = p(x,y,z)$，所以期望对三元联合分布取。
  • $I(X;Y\mid Z) = 0$ ⟺ 给定 $Z$ 条件独立：$p(x,y\mid z) = p(x\mid z)p(y\mid z)$。
  • 逐点版本 $i(x;y\mid z) = \log_2\frac{p(x\mid y,z)}{p(x\mid z)}$，也可以为负。
证明题套路
  1. 把每个条件熵按 $H(A\mid B) = H(A,B) - H(B)$ 展开成联合熵。
  2. 把 $(Y,Z)$ 当一个联合变量：$H(X\mid Y,Z) = H(X,Y,Z) - H(Y,Z)$。
  3. 两边都化成同一组联合熵，写「两式相同，得证 ∎」。

例题（样卷 Q22，5 分）：证明 $I(X;Y\mid Z) = H(X\mid Z) - H(X\mid Y,Z)$

$$\begin{aligned}\text{左边} &= [H(X,Z) - H(Z)] + [H(Y,Z) - H(Z)] - [H(X,Y,Z) - H(Z)]\\ &= H(X,Z) + H(Y,Z) - H(Z) - H(X,Y,Z)\\ \text{右边} &= [H(X,Z) - H(Z)] - [H(X,Y,Z) - H(Y,Z)]\\ &= H(X,Z) + H(Y,Z) - H(Z) - H(X,Y,Z)\end{aligned}$$

两式相同，得证。∎

题型 2　冗余 vs 协同 ★★★

最反直觉：条件化可以让互信息变大

条件化不是「减去 $Z$」，而是站在已知 $Z$ 的位置重新看 $X$ 与 $Y$。有些关系只有知道 $Z$ 才看得见。

比较名称典型例子$I(X;Y)$$I(X;Y\mid Z)$
$I(X;Y\mid Z) < I(X;Y)$冗余$X, Y, Z$ 是同一随机比特的拷贝10
$I(X;Y\mid Z) > I(X;Y)$协同$X = Y \oplus Z$，$Y, Z$ 独立均匀01

XOR：只看 $Y$，$X$ 仍是 50/50（取决于 $Z$），所以 $I(X;Y) = 0$；知道 $Z$ 后 $Y$ 完全决定 $X$，$I(X;Y\mid Z) = 1$ bit。信息只在组合里。

差值 $I(X;Y\mid Z) - I(X;Y)$ 只是净效应：现实数据同时有冗余和协同，会互相抵消。把它们分开是部分信息分解（PID），研究前沿，本课不深入。

CMI 是非线性版的偏相关，但偏相关的「扣掉 $Z$」直觉只在冗余时成立。

$Y$、$Z$ 是独立均匀比特，$X = Y \oplus Z$。$I(X;Y)$ 和 $I(X;Y\mid Z)$ 分别是？
  1. 1 bit，0 bits
  2. 0 bits，1 bit
  3. 1 bit，1 bit
  4. 0 bits，0 bits
协同：单独无信息，合起来 1 bit。A 是互为拷贝（冗余）的情形。

题型 3　链式法则与数据处理不等式 ★★

$$I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y) = I(X;Z) + I(X;Y\mid Z)$$
  • 信息回归：先看第一个变量解释多少，再看第二个在第一个之上额外解释多少。
  • 顺序无关，只要每步条件于已经看过的所有变量；中间项可以差很多，总和相同。
  • 也适用于逐点版本、加条件的版本。MI 可以独立公理化，关键公理就是这条可加性。

数据处理不等式

$X \to Y \to Z$ 是马尔可夫链 ⟺ $I(X;Z\mid Y) = 0$。用链式法则两种展开：

$$I(X;Y) + \underbrace{I(X;Z\mid Y)}_{=0} = I(X;Z) + \underbrace{I(X;Y\mid Z)}_{\ge 0}\ \Rightarrow\ I(X;Y) \ge I(X;Z)$$

处理链上信息只会丢，不会凭空增加。这条依赖马尔可夫假设；没有条件独立时（如 XOR），条件化可以让 MI 上升。

真实数据：Seinfeld 剧本

相邻字符 MI ≈ 0.7 bits；隔一个字符、条件于中间字符的 CMI 比 0.7 还大（协同：有了中间字符的上下文才看得出关系）。用链式法则累加前面各字符的贡献 0.7 + 0.7 + 0.5 + 0.3 + 0.2 + … ≈ 2.5 bits。

$X \to Y \to Z$ 构成马尔可夫链，一定成立的是？
  1. $I(X;Y) \ge I(X;Z)$
  2. $I(X;Z) \ge I(X;Y)$
  3. $I(X;Y\mid Z) = 0$
  4. $I(X;Z) = 0$
为 0 的是 $I(X;Z\mid Y)$，不是 $I(X;Y\mid Z)$。

简答练习

简答 · 讲课 Item 6证明数据处理不等式：若 $X \to Y \to Z$ 是马尔可夫链，则 $I(X;Y) \ge I(X;Z)$。

马尔可夫：给定 $Y$ 时 $X$、$Z$ 条件独立，$I(X;Z\mid Y) = 0$。

链式法则两种展开：$I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y) = I(X;Z) + I(X;Y\mid Z)$。

代入 0：$I(X;Y) = I(X;Z) + I(X;Y\mid Z) \ge I(X;Z)$，因为 CMI 非负。∎

简答 · 自拟证明 $I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y)$。

右边 $= [H(X) - H(X\mid Y)] + [H(X\mid Y) - H(X\mid Y,Z)] = H(X) - H(X\mid Y,Z)$。

把 $(Y,Z)$ 看成一个变量，这正是 $I(X;Y,Z)$ 的定义 $H(X) - H(X\mid Y,Z)$。∎

考前速记

  1. $I(X;Y\mid Z) = H(X\mid Z) - H(X\mid Y,Z)$；为 0 ⟺ 条件独立；非负，逐点可负。
  2. 证明题：全部拆成联合熵，$(Y,Z)$ 当一个变量。
  3. 冗余：CMI < MI（拷贝 1 → 0）；协同：CMI > MI（XOR 0 → 1）；差值只是净效应。
  4. 链式法则 = 信息回归，顺序无关。
  5. DPI：$X\to Y\to Z$ ⟹ $I(X;Y) \ge I(X;Z)$。
  6. 时序配对：x[:-1] 对 x[1:]，不跨场次。
