题型 1　自组织的定义与度量 ★★

Sayama：系统自发地随时间形成非平凡的宏观结构或行为的动态过程。两个特征：

  1. 组织度随时间增加；
  2. 动态不由中心化或外部控制主体引导（老师：不必完全没有，只要不是全部，比如交通有红绿灯）。

例子：Game of Life（二维 CA，二值格子、同步更新、同一条局部规则看 8 邻居；出现静止、闪烁、滑翔图案，最终密度几乎不依赖初始密度）、鸟群、蚂蚁、交通、大脑。

度量思路问题
熵的补（熵低 = 有组织）棋盘格和随机图案的单格熵一样，看不到变量间结构
Multi-information $\sum_i H(X_i) - H(X_1..X_k)$违反「一个分号」、重复计数（没有链式法则的保证）、高维难估（100×100 = 10 000 维）
Statistical complexity老师最喜欢，但不在本课范围

本课立场：自组织是信息的结构化。与其找一个总指标，不如刻画信息结构的多个方面（时间、空间、变量关系、存储、传递、与任务相关）以及它们怎样随时间变化。这就是 W9–W12。

为什么「熵的补」不能刻画自组织？
  1. 熵不能用于二值变量
  2. 棋盘格与随机图案单格熵相同
  3. 熵总会随时间增加
  4. 熵需要太多样本
单变量熵看不到变量之间的结构。

题型 2　措辞 → 度量 ★★★

考试题常不直接说度量名。先翻译：

题目说对应
最优编码这个取值要几个 bitShannon 信息量 $h(x)$
对哪个变量最不确定各变量的熵，取最大
「是否穿白衣」与「是否棕发」变量 → 平均量
「他穿着白衣」取值 → 逐点量
两者共同持有的信息MI（Venn 交集）
两者合起来的不确定性联合熵
告诉你 A，谁的不确定性减少最多以 A 为一方的 MI，取最大
misinformative / 误导逐点 MI < 0
已知打网球时……条件于某个取值，$I(W;B\mid T{=}\text{yes})$
A 完全基于 B 出招$I(A;B) > 0$ 且 $H(A\mid B) = 0$
上一局 → 下一局时滞 MI，源 [:-1]、目标 [1:]
「完全基于」为什么要两个条件

只有 MI > 0：有关系但没解释掉全部不确定性。只有 $H(A\mid B) = 0$：可能 A 本来就是常数（$H(A) = 0$），这时 MI 也是 0，不能说「基于 B」。

逐点 MI 在两个取值从未同时出现时无定义（条件概率是 0，log 0）。

判断「玩家 $V_i$ 完全基于 $V_7$ 出招」，需要检查的是？
  1. 只要 $I(V_i;V_7) > 0$
  2. 只要 $H(V_i\mid V_7) = 0$
  3. $I > 0$ 且 $H(V_i\mid V_7) = 0$
  4. $H(V_i) = H(V_7)$
排除「$V_i$ 本身就是常数」的情形。

题型 3　手算综合题 ★★★

例题（Calculation exercises Q1）

$p(x,y)$$x_1$$x_2$$p(y)$
$y_1$1/31/32/3
$y_2$1/41/121/3
$p(x)$7/125/12
  1. (a) 每个取值最少几个 bit → $h(x_1) = \log_2(12/7) = 0.78$，$h(x_2) = \log_2(12/5) = 1.26$ bits。
  2. (b) $H(Y) = 0.92$，$H(X,Y) = 2 \times \frac13\log_2 3 + \frac14 \times 2 + \frac1{12}\log_2 12 = 1.86$，$H(X\mid Y) = 0.94$ bits。
  3. 是否严格小于 $H(X) = 0.98$？不用算：$y_1$ 下 $x$ 等概率、$y_2$ 下不等 → 不独立 → 严格小于。
  4. (c) $I(X;Y) = 0.98 + 0.92 - 1.86 = 0.04$ bits；$Y$ 关于 $X$ 一样多（对称）。
得分习惯

单位必须写（四舍五入不在意）；严格不等号要说明为什么不在等号边界；约束题别漏概率表合法性给的界；参数曲线题先求参数的合法范围（每格在 [0, 1]）。

题型 4　同质性与案例 ★★

同质性：多个变量以相同方式运作，才能看作同一底层变量的不同实现、合并样本（样本量大增）。

  • Ising 模型的所有格子：✅ 可以合并。
  • 剪刀石头布不同玩家（各用不同策略）：❌ 应分别算。
数据集例子问题要点
IsingMI 随空间距离、温度怎么变低温全同、高温随机；临界 T ≈ 2.27 长程关联；所有格子对一起 addObservations；有限尺寸转变点偏高
MNIST哪个像素关于类别信息最多（特征选择）像素阈值 15 二值化；离散 MI（2 → 10）；按数字分组平均局部 MI
蚂蚁觅食形成信息素轨迹时位置的不确定性是否下降把同一时刻的所有蚂蚁当样本（同质性假设）；熵下降、MI 上升

模拟数据：丢掉暂态，多初始状态、多网络合并，并给出理由。

分析 Ising 模型时，把所有格子对的样本放进同一个 MI 计算，依据的是？
  1. 格子同质，以相同方式运作
  2. 格子之间相互独立
  3. 样本越多偏差越大

简答练习

简答 · Calc. ex. Q2(c)24 个角色里 5 人携带鞋子，其中 3 人有工作；不携带鞋子但有工作的有 $x$ 人。「携带鞋子」对「有工作」是误导性的，求 $x$ 的范围。

误导 ⟺ $i(S{=}\text{yes}; E{=}\text{yes}) < 0$ ⟺ $p(S{=}\text{yes}\mid E{=}\text{yes}) < p(S{=}\text{yes})$。

$\frac{3}{3+x} < \frac{5}{24} \iff 3 + x > 14.4 \iff x > 11.4$ → $x \ge 12$。

合法性：$p(S{=}\text{no}, E{=}\text{no}) = (19-x)/24 \ge 0$ → $x \le 19$。答案 $12 \le x \le 19$。

简答 · 自拟给出自组织的定义，并说明为什么这门课不用一个单一数字来度量它。

定义（Sayama）：系统在没有中心或外部控制的情况下，自发地随时间形成非平凡宏观结构 / 行为，即组织度随时间增加。

单一指标都有缺陷：熵的补看不到结构（棋盘格 vs 随机）；multi-information 重复计数、高维难估。所以改为刻画信息结构的多个方面（存储、传递、空间 / 时间关系）及其随时间的变化。

考前速记

  1. 自组织：组织度随时间增加 + 无（全部的）外部控制；自组织 = 信息结构化。
  2. 熵的补不行（棋盘格）；multi-information 重复计数、高维；statistical complexity 不考。
  3. 措辞：「是否」变量 / 「是」取值；共同持有 = MI；合起来 = 联合熵；误导 = 逐点 MI < 0；完全基于 = MI > 0 且条件熵 = 0。
  4. 严格不等号排除等号（独立）；约束题加合法性界；写单位。
  5. 同质才能合并样本：Ising ✅，不同策略的玩家 ❌。
