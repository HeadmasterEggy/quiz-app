题型 2　记号与核心问题 ★

$$\mathbf X_n^{(k)} = \{X_{n-k+1}, \dots, X_{n-1}, X_n\}\quad\text{（以 } X_n \text{ 结尾，预测 } X_{n+1}\text{）}$$

核心问题：目标变量下一个值 $x_{n+1}$ 的信息从哪里来？来自自己过去的有多少（存储），来自其他源的有多少（传递），归因于哪个源，能否分割、会不会重叠。

$$H(X_{n+1}) = \underbrace{I(\mathbf X_n^{(k)}; X_{n+1})}_{\text{存储（W10）}} + \underbrace{I(Y_n; X_{n+1}\mid\mathbf X_n^{(k)})}_{\text{传递（W11）}} + \underbrace{H(X_{n+1}\mid\mathbf X_n^{(k)}, Y_n)}_{\text{剩余}}$$

题型 3　熵率 ★★★

$$H'_{\mu X} = \lim_{n\to\infty}\frac1n H(X_1, \dots, X_n)\qquad H_{\mu X} = \lim_{n\to\infty} H(X_n \mid X_1, \dots, X_{n-1})$$
  • 前者是块熵 vs n 的渐近斜率（平均每符号的熵）；后者是给定过去后下一个值的条件熵（块熵的增量，链式法则）。
  • 平稳过程两者相等。注意本课撇号和 Cover & Thomas 相反。
  • 含义：把过程自身的过去当第一个信息源后，还剩多少不确定性；每一步真正「新」的信息。
  • 编码含义：有记忆信源利用全部历史时，每个符号的最小平均码长（英文 th 后 e 很可能）。
$$A_X = H(X) - H_{\mu X}\qquad\text{（下一个值的不确定性 = 来自过去的 + 剩下的）}$$
过程$H(X)$$H_\mu$$A_X$
i.i.d.$H(X)$$H(X)$0
周期 0101…101

例题：两状态马尔可夫链（W11 heartbeat 的源）

$p(1\mid0) = 0.05$，$p(0\mid1) = 0.2$。平稳分布 $p(0) = \frac{0.2}{0.25} = 0.8$，$p(1) = 0.2$。

$$H_\mu = 0.8\,H_b(0.05) + 0.2\,H_b(0.2) = 0.8(0.286) + 0.2(0.722) \approx 0.374\ \text{bits}$$

$H(X) = H_b(0.2) = 0.722$，所以 $A_X \approx 0.348$ bits。

块熵图：i.i.d. 是过原点的直线；周期 2 升到 1 bit 后水平；一般过程逐渐逼近斜率 $H_\mu$ 的直线，渐近线的截距 = excess entropy（W10）。

简答练习

简答 · 自拟两状态马尔可夫链 $p(1\mid0) = 0.1$，$p(0\mid1) = 0.4$。求平稳分布、熵率和 AIS（$k = 1$）。

$p(0) = \frac{0.4}{0.4 + 0.1} = 0.8$，$p(1) = 0.2$。

$H_\mu = 0.8\,H_b(0.1) + 0.2\,H_b(0.4) = 0.8(0.469) + 0.2(0.971) = 0.375 + 0.194 = 0.569$ bits。

$H(X) = H_b(0.2) = 0.722$，$A_X = 0.722 - 0.569 = 0.153$ bits（一阶马尔可夫，$k = 1$ 已足够）。

考前速记

  1. 计算 = 存储（AIS）+ 传递（TE）+ 修改；生物计算分布式、持续、随机。
  2. $\mathbf X_n^{(k)}$ 以 $X_n$ 结尾，预测 $X_{n+1}$。
  3. 熵率：块熵斜率 = 给定过去的条件熵（平稳时）；已知过去后剩下的不确定性。
  4. $A_X = H(X) - H_\mu$；i.i.d. 熵率 = $H(X)$；周期过程熵率 0。
  5. 马尔可夫链：$p(0) = \lambda_0/(\lambda_0 + \lambda_1)$，$H_\mu = \sum_x p(x)H_b(\text{离开 } x)$。
