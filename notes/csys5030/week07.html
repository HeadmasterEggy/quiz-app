题型 1　Surrogate 与 p 值 ★★★

理论上 $I = 0$ ⟺ 独立，但有限样本即使独立也几乎总测出非零值。问题是：这个值与 0 一致吗？

$$H_0:\ X \perp Y\qquad p = P\big(I_{\text{surr}} \ge I_{\text{meas}} \mid H_0\big)\qquad p < \alpha = 0.05 \Rightarrow \text{拒绝 } H_0$$
生成 surrogate 分布
  1. 原配对算实测值 $I_{\text{meas}}$。
  2. 打乱源 $Y$：保留 $Y$ 的边际分布，破坏 $X$、$Y$ 的联合依赖；算一次 MI。
  3. 重复 $S$ 次得到零分布（噪声底）。
  4. p 值 = surrogate 中 ≥ 实测值的比例。
  • 时间序列：打乱会破坏自相关，改用旋转（循环平移）一条序列。
  • CMI 检验：打乱源，保持目标和条件变量在一起。
  • 偏差修正：$I_{\text{corr}} = I_{\text{meas}} - \langle I_{\text{surr}}\rangle$。离散时也有人除以熵把 MI 归一化到 [0, 1]。
  • JIDT 默认 100 个 surrogate，太少；bootstrap 的 p 值本身是随机的，弱关系时会跳。
打乱源变量 $Y$ 来生成 surrogate，目的是？
  1. 同时保留边际和联合依赖
  2. 保留边际分布、破坏联合依赖
  3. 破坏边际分布、保留联合依赖
  4. 减少样本数加快计算
得到「若独立会测到什么」的分布。

题型 2　解析 χ² vs bootstrap ★★

Bootstrap（surrogate）解析（χ²）
谁能用所有估计器Discrete（自由度看字母表大小）、Gaussian（看维数）；KSG 没有
速度慢快
随机性p 值随机确定
准确surrogate 够多时最准近似；小样本、时间序列时不准

原理（不用背）：$H_0$ 下 $2N \cdot I$（nats）近似 χ²；离散自由度 $(|\mathcal A_X|-1)(|\mathcal A_Y|-1)$，Gaussian $d_X d_Y$。单变量 Gaussian 零分布均值 ≈ $1/(2N)$：样本多 10 倍，零分布缩到约 1/10。

JIDT 里哪个估计器不能勾选「解析显著性」？
  1. Discrete
  2. Gaussian
  3. KSG
  4. 三个都能
KSG 的零分布没有已知解析形式。

题型 3　样本量与「不显著」 ★★★

「需要多少样本」要先说清楚问什么：

  • 检测到显著关系：取决于关系多强，越弱越要多。
  • 避免欠采样：取决于估计器，Gaussian 比 KSG 要的少（model-based）。
$$\text{离散启发式：}\ N \ge 3 \times \text{状态配置数（下限）},\quad N \ge 10\times\text{（像样）},\quad \text{状态配置数} = \prod_i |\mathcal{A}_i|$$

假设各配置大致等可能；分布偏斜要更多。Seinfeld 27 个字符：前 1 个 → 下一个是 $27^2 = 729$ 个配置，10× 约 7 300；前 2 个 → $27^3 = 19\,683$，约 20 万。每往回多看一个，指数增长。

连续：kernel width 大致不超过标准差；15 个样本用任何连续估计器都不会好。

surrogate 实验（Item 4）

设置结果
N 100 → 1000（无耦合）零分布窄了约 10 倍
N = 1000，耦合 0.01p = 0.12，不显著，但确实有弱耦合
N = 10 000，耦合 0.05远在零分布之外，强显著
KSG，N = 1000零分布以 0 为中心、可负、宽得多（±0.06 vs Gaussian < 0.01）
不显著 ≠ 没有关系

只能说「现有样本量下无法拒绝零假设」。样本多了，实测值更稳、零分布更窄，弱关系更容易冒出来。

$X$、$Y$ 各有 4 个取值，用离散估计 MI。按「10×」的启发式，大约需要多少样本？
  1. 40
  2. 80
  3. 160
  4. 16
状态配置数 4 × 4 = 16，×10。

题型 4　自相关与非平稳 ★★★

自相关让样本不独立，而独立是估计器、尤其显著性检验的前提：

  • Gaussian 解析检验：把 N 当独立样本数，自相关时失真。
  • KSG：时间相邻的样本在联合空间也挨得近 → 近邻被它们占据 → 盒子变小 → 边际计数变少 → MI 被人为抬高。
  • Surrogate：打乱破坏了源的自相关。
修正步骤
  1. 画自相关图，看自相关到第几个滞后才进入显著性带内（或第一次过零）。
  2. 取两个变量里最长的自相关长度，设 DYN_CORR_EXCL（Theiler window）：找近邻时忽略时间上太近的样本。
  3. 重新估计，看 MI 是否下降、是否仍显著。神经数据（尤其 fMRI）几乎总要加。
非平稳

股价这类严重非平稳的数据，样本不来自同一过程，Theiler window 也救不了。先取差分或 log 差分（log returns）变平稳，这同时把问题变成「每日变化之间的关系」。

某变量自相关在滞后 1 约 0.95，平滑衰减，到滞后约 15 仍显著。可以推出？①用 KSG 应设 dynamic correlation exclusion　②应预期显著的 AIS
  1. 只有 ①
  2. 只有 ②
  3. ① 和 ② 都对
  4. 都不对
① Theiler window ≈ 15；② 强自相关意味着过去能预测下一个值（W10 的信息存储）。

题型 5　多个滞后都有 MI：用 CMI 区分 ★★

心率 → 呼吸的 KSG MI 在多个滞后都不小，最大在 lag 7 ≈ 0.144 nats。两种可能：只有一个机制但自相关造成相邻滞后的假象；或真有多个机制。

$$I\big(\text{breath}_t;\ \text{heart}_{t-l}\ \big|\ \text{heart}_{t-7}\big)$$
  • CMI = 0（显著性检验后）：lag $l$ 没有新信息，冗余。
  • CMI > 0：额外信息可能是独有的，也可能是协同的，或两者都有（条件化去冗余、加协同）。
  • 两个源一起：$I(X;Y,Z) = I(X;Y) + I(X;Z\mid Y)$。
  • 局部 MI：computeLocalOfPreviousObservations()，顺序和输入样本一致；高局部 MI 集中在心率高（85–92）的区域。

简答练习

简答 · 自拟你用 KSG 测两个 EEG 通道之间的 MI，得到 0.08 nats。写出你接下来要做的两项检查，各自为什么要做。

1. 统计显著性：用（旋转的）surrogate 生成零分布，算 p 值。有限样本下即使独立也会测到非零值，要判断 0.08 是否与 0 一致。

2. 自相关：神经数据几乎总是强自相关，画自相关图，把最长自相关长度设为 DYN_CORR_EXCL 重算；否则近邻被时间相邻样本占据，MI 被抬高，检验也失真。（也可答：检查平稳性。）

简答 · 自拟心率在滞后 3 和滞后 7 都对呼吸有显著 MI。怎样判断滞后 3 是否提供了滞后 7 之外的信息？如果有，可能是哪种信息？

算 $I(\text{breath}_t; \text{heart}_{t-3}\mid\text{heart}_{t-7})$ 并做显著性检验（打乱源，保持目标与条件在一起）。

不显著：滞后 3 的信息与滞后 7 冗余（可能只是自相关）。显著：提供了额外信息，可能是独有信息，也可能是两者合起来才有的协同信息，或都有。

考前速记

  1. $H_0$ 独立；p = surrogate ≥ 实测的比例；打乱保边际破联合；时间序列用旋转；CMI 保目标与条件在一起。
  2. 偏差修正 $I - \langle I_s\rangle$；默认 100 个 surrogate 太少；bootstrap p 值随机。
  3. χ² 解析：Discrete、Gaussian 有，KSG 没有；快、确定、近似。
  4. N ≥ 3×（最好 10×）状态配置数，配置数指数增长；不显著 ≠ 无关。
  5. 样本多 → 零分布窄、实测稳；KSG 零分布以 0 为中心、更宽。
  6. 自相关 → DYN_CORR_EXCL = 最长自相关长度；非平稳 → log 差分。
  7. 多滞后都有 MI：用 CMI，= 0 冗余，> 0 独有或协同。
