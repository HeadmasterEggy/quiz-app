题型 1　计算 vs 估计：plug-in、偏差、方差 ★★

  • 有真实分布就是「计算」；只有有限样本，从数据估概率再代入，就是「估计」。
  • 前四周用的 plug-in 估计（频率直接当概率）就是最大似然估计（MLE）：给定这批数据最可能的值。但数据是随机的，估计值本身也是随机变量。
  • 偏差：估计值平均偏离真值多少。方差：换一批同样大小的样本，估计值波动多大。
  • 小样本 plug-in：熵偏低，MI 偏高（W6–W7 展开）。
  • 只用 Shannon 家族；Rényi 熵（概率取幂）满足不同公理，回答不同问题。传递熵等后面的量都只是 CMI 的特例。
从样本数出频率、直接代入公式算熵，这种估计叫什么？
  1. KSG 估计
  2. plug-in 估计（MLE）
  3. 核估计
  4. 高斯估计
频率就是概率的最大似然估计。

题型 2　记号规则与 1 bit 的含义 ★★

量逗号分号条件竖线
熵 $H(X_1, X_2 \mid Z_1, Z_2)$任意0最多 1
MI $I(X_1, X_2; Y_1 \mid Z_1, Z_2)$任意恰好 1最多 1

分号只在竖线左边。两个以上变量的「互信息」没有公认定义。

1 bit ⟺ 后验是先验的 2 倍

$$i(x;y) = 1\ \text{bit} \iff \frac{p(x\mid y)}{p(x)} = 2$$

轮盘 36 个数：$p(4) = 1/36$，知道是黑色后 $p(4\mid\text{黑}) = 1/18$。这和字母表大小无关；换成 $\log_4$ 时，1 个单位对应比值 4。不一定字面上「排除一半选项」，可能只是重新分配概率。

例题（讲课）：Guess Who 的角与眉毛

有眉毛无眉毛合计
有角325
无角81119
合计111324
$$i(\text{有角};\text{有眉毛}) = \log_2\frac{3/5}{11/24} = \log_2\frac{72}{55} \approx 0.39\ \text{bits}$$
下面哪个写法不合法？
  1. $H(X, Y \mid Z)$
  2. $I(X; Y, W \mid Z)$
  3. $H(X; Y)$
  4. $I(X, W; Y)$
熵里没有分号。

题型 3　JIDT 使用流程 ★★

JIDT（Java Information Dynamics Toolkit）：Java 写的，Python 通过 JPype 调用；支持离散和连续数据，后面的传递熵等都有。AutoAnalyser GUI 生成 Java / Python / MATLAB 代码。

生成代码的五步
  1. 启动 JVM，连上 infodynamics.jar。
  2. 读数据（CSV：行 = 样本，列 = 变量）。
  3. 构造 calculator，设属性（如离散的 base）。
  4. initialise()（可重复调用以清空、复用对象）。
  5. setObservations() / 多次 addObservations()，再 computeAverageLocalOfObservations()；要局部值用 computeLocalOfPreviousObservations()。
  • 离散 calculator 只接受整数 0 到 base−1；数据是 0–3 却设 base = 2 会报错。
  • 演示：两列耦合数据，同一行对齐 MI = 0.0007 bits；打开 time difference（滞后一步）后 = 1.0002 bits。样本怎么配对决定结论。
  • 考试不需要记方法名、属性名，但可能给 AutoAnalyser 的输出让你修改。
同一份两列数据，同行对齐 MI ≈ 0，滞后一步 MI ≈ 1 bit。最合理的解释是？
  1. 估计器出了 bug
  2. 两列的耦合体现在滞后一步
  3. 样本量不够
  4. base 设错了
样本配对方式回答的是不同的问题。

题型 4　写代码（简答） ★★★

考试给一个样例库（plug-in，离散），函数说明会印在卷子上：

entropy_empirical(xn)
jointentropy_empirical(xn, yn)
conditionalentropy_empirical(xn, yn)
mutualinformation_empirical(xn, yn)
conditionalmutualinformation_empirical(xn, yn, zn)
  • xn[i] 是第 i 个样本；多维变量用二维数组（行 = 样本，列 = 维度）；各参数同下标是对应样本。
  • 看逻辑流程，语法小错不扣分；不会写的语法可以用注释描述拿部分分。
三个得分点
  1. 「每个变量的熵」→ 循环每一列。
  2. 「联合不确定性」→ 把几列切成一个二维数组传进去，不能把熵相加（只有独立才成立）。
  3. 「上一局对下一局」→ 源 [:-1]、目标 [1:] 对齐；求最大时排除自己。

例题（样卷 Q23，7 分）：多人游戏，行 = 一局，列 = 玩家

# a) 每个玩家出招的熵
for i in range(data.shape[1]):
    print(i + 1, entropy_empirical(data[:, i]))

# b) 玩家 1、2、3 的联合熵：三列作为一个多维变量
H123 = entropy_empirical(data[:, 0:3])

# c) 玩家 1 上一局的出招，对哪个其他玩家下一局的出招信息最多
best, bestMI = -1, -1.0
for j in range(1, data.shape[1]):              # 排除玩家 1
    mi = mutualinformation_empirical(data[:-1, 0], data[1:, j])
    if mi > bestMI:
        best, bestMI = j, mi
要算玩家 1 上一局出招和玩家 2 下一局出招的 MI，参数应该怎么传？
  1. data[:, 0], data[:, 1]
  2. data[1:, 0], data[:-1, 1]
  3. data[:-1, 0], data[1:, 1]
  4. data[:-1, 0], data[:-1, 1]
源去掉最后一行，目标去掉第一行，第 n 行对第 n+1 行。A 是同一局；B 方向反了。

简答练习

简答 · 自拟数据 data 行 = 时间步，列 0 是温度 $X$（已离散化），列 1 是湿度 $Y$，列 2 是风 $Z$。用样例库写代码：(a) 算 $I(X;Y)$；(b) 算 $Y$ 当前值对 $X$ 下一时刻值的信息，条件于 $X$ 当前值。 
# a)
mi = mutualinformation_empirical(data[:, 0], data[:, 1])

# b) 源 = Y 当前，目标 = X 下一时刻，条件 = X 当前
cmi = conditionalmutualinformation_empirical(
        data[:-1, 1],   # y_n
        data[1:, 0],    # x_{n+1}
        data[:-1, 0])   # x_n
print("%.4f bits" % cmi)

(b) 就是 W11 的传递熵 $I(Y_n; X_{n+1}\mid X_n)$。得分点：三个参数都用同一组下标对齐，写单位。

考前速记

  1. plug-in = MLE；估计值是随机变量；偏差 = 平均偏离，方差 = 换样本的波动。
  2. 熵没有分号；MI 恰好一个分号；条件竖线最多一个。
  3. 1 bit ⟺ 后验 / 先验 = 2，与字母表无关。
  4. JIDT：构造 → 属性 → initialise → set/addObservations → compute；离散值 0..base−1。
  5. 代码题：联合用二维数组；时滞 [:-1] 对 [1:]；排除自己；写单位；不会的语法写注释。
