题型 1　偏差、方差与分箱 ★★

$$\text{Bias} = \mathbb{E}[\hat H_N] - H_{\text{true}}\qquad \text{Variance：同样大小的不同样本集之间估计值的波动}$$
  • 偏差取决于估计器类型 + 样本数，样本越多越小。
  • 有限样本下熵通常低估，MI 通常高估（现实中多是弱关系）；不绝对，硬币和它的拷贝算 MI 会低估。
  • 离散 plug-in 的 Miller–Madow 修正：$\hat H_{\text{MM}} = \hat H + \frac{|\mathcal{A}_X| - 1}{2N}$（nats），JIDT 没有内置。
  • 分箱（binning）：把连续值切成区间再用离散估计器。问题：对箱数和分箱方式敏感、没有标准答案；分界线两侧的近邻被当成完全不同。等宽是 JIDT 默认，也可以等频（max-entropy）。

题型 2　微分熵 ★★

$$h(X) = -\int f(x)\log f(x)\,dx\qquad H_\Delta \approx h(X) - \log\Delta$$
  • 连续变量问 $P(X = a)$ 没意义；PDF 是单位长度上的概率质量，$P(X \in [a, a+\Delta]) \approx f(a)\Delta$。
  • 离散化宽度 $\Delta \to 0$ 时 $-\log\Delta \to \infty$：一个真正的实数有无穷多不确定性。$h(X)$ 是不发散的那部分，主要用于比较（相减时 $\log\Delta$ 抵消）。
操作结果
平移 $X + c$$h$ 不变
缩放 $aX$$h(aX) = h(X) + \log|a|$；$|a| < 1$ 时可以为负
Uniform[0, 1]$h = 0$，可作参照

好消息：MI、CMI、条件熵都是熵的和差，发散项抵消。连续 MI 非负、对缩放不变，等于离散化取极限的结果。MI 比熵有用得多。

关于连续变量，下面哪个量可能是负数？
  1. 互信息 $I(X;Y)$
  2. 条件互信息 $I(X;Y\mid Z)$
  3. 微分熵 $h(X)$
  4. 离散化后的熵 $H_\Delta$
把分布缩窄到比 Uniform[0,1] 还窄时 $h < 0$。MI、CMI 的真值仍非负。

题型 3　高斯估计器与 $\rho$ ★★★

$$h(\mathbf X) = \tfrac12\ln\big((2\pi e)^d|\Omega_X|\big)\qquad\Rightarrow\qquad I(X;Y) = -\tfrac12\ln(1-\rho^2)\ \text{nats}$$
推导步骤（必会）
  1. $h(X) = \frac12\ln(2\pi e\sigma_x^2)$，$h(Y) = \frac12\ln(2\pi e\sigma_y^2)$。
  2. 协方差矩阵行列式 $|\Omega_{XY}| = \sigma_x^2\sigma_y^2 - \rho^2\sigma_x^2\sigma_y^2 = \sigma_x^2\sigma_y^2(1-\rho^2)$。
  3. $h(X,Y) = \frac12\ln\big((2\pi e)^2\sigma_x^2\sigma_y^2(1-\rho^2)\big)$。
  4. $I = h(X) + h(Y) - h(X,Y)$，$(2\pi e)^2\sigma_x^2\sigma_y^2$ 抵消。
  • 与 $\rho$ 的符号无关：负相关时知道 $X$ 照样能预测 $Y$。信息论不带语义，只说强度不说方向。
  • $\rho \to \pm1$ 时 MI → ∞；真实数据里看到 MI 爆到无穷，通常是某列被复制了。
  • 比相关系数强：能推广到多变量、有链式法则。
  • Model-based：模型对就又准又快又省数据，模型错就错。只看线性分量；对 MI 是真值的下界，对 CMI 不一定。
  • 单位：离散惯用 bits，连续惯用 nats（JIDT 的 Gaussian、KSG 输出 nats；核估计器例外，输出 bits）。

例题（自拟）

$\rho = 0.6$：$I = -\frac12\ln(1 - 0.36) = -\frac12\ln 0.64 = 0.223$ nats $= 0.322$ bits。

两个高斯变量相关系数 $\rho = -0.8$，它们的 MI 是？
  1. 负数，因为负相关
  2. $-\frac12\ln 0.36 \approx 0.51$ nats
  3. $-\frac12\ln 0.2 \approx 0.80$ nats
  4. 0，因为相关为负
$1 - \rho^2 = 0.36$；与符号无关。

题型 4　核估计器 vs KSG ★★★

Box kernelKSG（Kraskov）
邻域固定半径 $r$（KERNEL_WIDTH，默认 0.25 个标准差）联合空间第 $k$ 近邻决定宽度（默认 $k = 4$）
估计数竖条、横条、方盒里的点：$\hat I = \frac1N\sum\log\frac{\hat p(x,y)}{\hat p(x)\hat p(y)}$数边际空间邻居 $n_x, n_y$，代入 digamma：$\psi(k) - \frac1k - \langle\psi(n_x) + \psi(n_y)\rangle + \psi(N)$（算法 2）
非线性能能
参数敏感极敏感：$r$ 小 → 欠采样高估；$r$ 大 → 丢细节低估稳定得多（$k$ 4 → 15 只差约 25%）
偏差修正没有内置
负值可能输出负值 = 与 0 一致，不是 bug
  • 核估计器是动态离散化（以每个点为中心），是过渡工具，帮助理解 KSG。
  • KSG 动态宽度：稀疏区域放大盒子防欠采样，密集区域缩小看细节。算法 1 偏差大方差小（便于比较），算法 2 偏差小方差大（本课默认）。
  • KSG 为数值稳定会加一点随机噪声，每次结果略有不同。
  • 已知数据是线性高斯时，Gaussian 估计器最好。
Box-kernel 估计器相对 KSG 的优势是？

  2. 能做显著性检验
  3. 能处理多维变量
  4. 以上都是
  5. 以上都不是
这些 KSG 也都能做；KSG 还有自适应宽度和偏差修正。

题型 5　Gaussian + KSG 四象限 ★★★

同一数据同时跑两个估计器：

KSG ≈ 0KSG > 0
Gaussian ≈ 0① 没关系，或太弱、样本不够测不出② 只有非线性关系
Gaussian > 0④ 有线性关系，KSG 数据不够还没「追上」③ 有线性关系；KSG 多出的是非线性分量

④ 不矛盾：model-based 估计器很快锁定符合模型的关系；model-free 估计器要考虑所有关系、又大力做偏差修正，更保守、需要更多数据。

例题：睡眠呼吸暂停患者的心率与呼吸

Gaussian 在各滞后都只有千分之几 nats；KSG 约 0.13 nats，高两个数量级 → 象限 ② 非线性关系。不能因为 Gaussian ≈ 0 就说「没有关系」。

Gaussian 估计 MI = 0.0010 nats（p = 0.28），KSG 估计 MI = 0.1347 nats（p = 0）。结论是？
  1. 检测到线性，检测不到非线性
  2. 线性、非线性都检测到了
  3. 检测到非线性，检测不到线性
  4. 没有检测到任何关系
就是心跳-呼吸数据的情形（象限 ②）。

简答练习

简答 · 讲课 Item 3已知高斯熵 $h(\mathbf X) = \frac12\ln((2\pi e)^d|\Omega|)$。推导相关系数为 $\rho$ 的两个高斯变量的 MI，并说明 $\rho$ 的符号为什么不影响结果。

$|\Omega_{XY}| = \sigma_x^2\sigma_y^2(1-\rho^2)$；$I = \frac12\ln(2\pi e\sigma_x^2) + \frac12\ln(2\pi e\sigma_y^2) - \frac12\ln((2\pi e)^2\sigma_x^2\sigma_y^2(1-\rho^2)) = -\frac12\ln(1-\rho^2)$ nats。

只依赖 $\rho^2$。负相关时知道 $X$ 一样能预测 $Y$，只是方向相反；信息论只量强度，不带语义。

简答 · 自拟同一组数据，Gaussian MI = 0.002 nats，KSG MI = 0.15 nats。解释可以得出什么结论，不能得出什么结论。

KSG 明显大于 0 而 Gaussian 接近 0 → 有非线性关系，线性分量几乎没有。

不能说「没有关系」（Gaussian 只看线性）；没做显著性检验前，也不能完全确定 0.15 不是偏差（W07）；也不能说是因果。

考前速记

  1. Bias = 期望 − 真值；熵常低估，MI 常高估；分箱对箱数敏感。
  2. 微分熵：$H_\Delta \approx h - \log\Delta$；可为负；平移不变，缩放加 $\log|a|$；只用于比较。MI 照旧非负、缩放不变。
  3. 高斯：$I = -\frac12\ln(1-\rho^2)$ nats；与符号无关；只看线性；MI 下界。
  4. Kernel：固定 $r$，极敏感，输出 bits。KSG：第 $k$ 近邻（4），digamma 偏差修正，稳定，可负 = 与 0 一致，算法 2 默认。
  5. 四象限：G≈0 K>0 非线性；G>0 K≈0 线性但 KSG 数据不够。
  6. JIDT：属性用字符串设，改完必须 initialise()。
