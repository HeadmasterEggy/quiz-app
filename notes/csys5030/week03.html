题型 1　算互信息、Venn 图 ★★★

$$I(X;Y) = H(X) + H(Y) - H(X,Y) = H(X) - H(X\mid Y) = H(Y) - H(Y\mid X)$$

Venn 图：两个圆分别是 $H(X)$、$H(Y)$，重叠部分是 $I(X;Y)$，各自剩下的是条件熵，总面积是 $H(X,Y)$。

性质说明
非负$I \ge 0$；$I = 0$ ⟺ 独立
对称$I(X;Y) = I(Y;X)$
上界$I \le \min(H(X), H(Y))$：重叠不能大于小圆
自信息$I(X;X) = H(X)$
解法步骤（给联合概率表）
  1. 求边际，算 $H(X)$、$H(Y)$。
  2. 逐格算 $H(X,Y)$。
  3. $I = H(X) + H(Y) - H(X,Y)$，检查 $0 \le I \le \min$。

例题（样卷 Q11 的表）

$p(0,0) = 0.5$，$p(0,1) = 0.1$，$p(1,0) = 0.1$，$p(1,1) = 0.3$：$H(X) = H(Y) = 0.971$，$H(X,Y) = 1.685$ → $I = 0.971 + 0.971 - 1.685 = $ 0.257 bits。

Venn 图中 α 是只属于 $X$ 的部分，β 是重叠，γ 是只属于 $Y$ 的部分。α + β + γ 等于？（A $H(X)+H(Y)$　B $H(X,Y)$　C $H(X)+H(Y)-I(X;Y)$）
  1. A
  2. B
  3. C
  4. A 和 B
  5. B 和 C
总面积是联合熵；把两个圆相加会把重叠算两次，所以要减一次 $I$。

题型 2　逐点互信息与误导信息 ★★★

$$i(x;y) = \log_2\frac{p(x\mid y)}{p(x)} = \log_2\frac{p(x,y)}{p(x)p(y)} = h(x) - h(x\mid y)\qquad I(X;Y) = \langle i(x;y)\rangle$$
  • 样卷 Q2：Shannon 信息量之于熵，就像逐点 MI 之于 MI（局部值与平均值）。
  • $i < 0$ = 误导信息：$y$ 让实际发生的 $x$ 看起来更不可能，$p(x\mid y) < p(x)$。平均值非负，单点可以为负。
  • 若 $p(x,y) = 0$（这对组合从没出现），$i$ 无定义。

例题（讲课）：天气预报

基准 $p(\text{雨}) = 0.2$。预报晴却下雨：$p(\text{雨}\mid\text{晴}) = 0.05$ → $\log_2(0.05/0.2) = $ −2 bits（误导）。预报雨且下雨：$\log_2(0.8/0.2) = $ +2 bits。

真实数据：Seinfeld 剧本里相邻字符 Z→Z 最强、Q→U 强正，V→N 为负。

$p(0,0) = 0.5$，$p(0,1) = 0.1$，$p(1,0) = 0.1$，$p(1,1) = 0.3$。哪一对是误导性的？
  1. $x{=}0, y{=}0$
  2. $x{=}0, y{=}1$
  3. $x{=}1, y{=}1$
  4. 都不是
$\log_2\frac{0.1}{0.6 \times 0.4} = \log_2 0.417 < 0$。另两个比值 0.5/0.36、0.3/0.16 都 > 1。

题型 3　误导信息的约束（简答） ★★★

解法步骤
  1. 误导 ⟺ $i(x;y) < 0$ ⟺ $p(x\mid y) < p(x)$。
  2. 用未知数写出 $p(y)$ 和 $p(x\mid y) = p(x,y)/p(y)$，解不等式。
  3. 加上概率表合法性（每格 $\ge 0$）给出另一侧的界；人数题要取整。

例题（样卷 Q21）

Guess Who 24 人：$p(x{=}1) = 5/24$，$p(x{=}1, y{=}1) = 3/24$，$p(x{=}0, y{=}1) = \alpha/24$。要 $y{=}1$ 对 $x{=}1$ 误导：

$$p(x{=}1\mid y{=}1) = \frac{3}{3+\alpha} < \frac{5}{24} \iff 72 < 15 + 5\alpha \iff \alpha > 11.4$$

α 是人数 → $\alpha \ge 12$；合法性 $p(x{=}0, y{=}0) = (19-\alpha)/24 \ge 0$ → $\alpha \le 19$。答案 $12 \le \alpha \le 19$。

(b) α = 5 时，得知 $x{=}0, y{=}0$：$p = 14/24$，$h = \log_2(24/14) \approx $ 0.78 bits（联合事件的信息量）。

常丢的分

只写 α > 11.4，忘了另一侧的合法性界；或「严格小于」时没排除等号（等号是独立，$i = 0$）。

题型 4　解读与样本混池的坑 ★★

视角互信息是……
KL 散度真实联合分布与「假设独立」的分布 $p(x)p(y)$ 之间的 KL 散度
Bayesian（老师最爱）$\langle\log_2 p(x\mid y)/p(x)\rangle$：后验比先验的对数期望
编码假设独立编码、不利用相依关系所多花的码长
统计对独立性的偏离；$I = 0$ ⟺ 独立
相关性非线性版本的相关，model-free
样本混池

一个玩家第一组全出石头、第二组全出剪刀、第三组全出布，把样本拼在一起算熵 ≈ $\log_2 3$，看起来「很随机」。熵答的是「随机抽一个样本有多不确定」，不关心时序；完美循环的策略也是满熵。想问「可预测性」要用 $H(\text{next}\mid\text{prev})$。老师：it's answering that question perfectly, just not the question we think we're asking.

措辞：「共同持有的信息」= MI；「合起来的不确定性」= 联合熵；「是否 X」说的是变量，「是 X」说的是取值。

$X$ 的分布 (0.7, 0.1, 0.1, 0.1)，$Y$ 的分布 (0.7, 0.3)。只知道这些，一定成立的是？
  1. $H(X) > H(Y)$
  2. $h(x{=}0) > h(y{=}0)$
  3. $I(X;Y) > 0$
  4. 以上都不对
$H(X) = 1.36 > H(Y) = 0.88$；$h(x{=}0) = h(y{=}0)$ 相等；只有边际无法判断 MI。

题型 5　交叉熵与 KL 散度 ★

$$H(P,Q) = \sum_x p(x)\log_2\frac{1}{q(x)}\qquad D(P\|Q) = H(P,Q) - H(P) = \sum_x p(x)\log_2\frac{p(x)}{q(x)} \ge 0$$
  • 交叉熵：真实分布是 $P$，却按 $Q$ 设计编码时的平均码长；机器学习的 loss。
  • KL：用错分布编码多付的代价。$I(X;Y) = D\big(p(x,y)\,\|\,p(x)p(y)\big)$。
  • 老师说后面不会再用，但值得懂。

简答练习

简答 · 样卷 Q21 改Guess Who 24 人，$p(x{=}1) = 6/24$，$p(x{=}1, y{=}1) = 2/24$，$p(x{=}0, y{=}1) = \alpha/24$。$y{=}1$ 对 $x{=}1$ 是误导性的，求 α 的取值范围。

误导 ⟺ $p(x{=}1\mid y{=}1) < p(x{=}1)$。$p(y{=}1) = (2+\alpha)/24$，$p(x{=}1\mid y{=}1) = 2/(2+\alpha)$。

$\frac{2}{2+\alpha} < \frac{6}{24} = \frac14 \iff 8 < 2 + \alpha \iff \alpha > 6$ → $\alpha \ge 7$。

合法性：$p(x{=}0) = 18/24$，$p(x{=}0, y{=}0) = (18-\alpha)/24 \ge 0$ → $\alpha \le 18$。答案 $7 \le \alpha \le 18$。

简答 · 自拟从 $I(X;Y) = H(X) + H(Y) - H(X,Y)$ 推出 $I(X;Y) = H(X) - H(X\mid Y)$。

由 $H(X\mid Y) = H(X,Y) - H(Y)$ 得 $H(X,Y) = H(Y) + H(X\mid Y)$。

代入：$I = H(X) + H(Y) - H(Y) - H(X\mid Y) = H(X) - H(X\mid Y)$。∎

考前速记

  1. $I = H(X) + H(Y) - H(X,Y) = H(X) - H(X\mid Y)$；非负、对称、$\le \min H$；$I(X;X) = H(X)$。
  2. Venn：重叠 = MI，总面积 = 联合熵 = $H(X) + H(Y) - I$。
  3. $i(x;y) = \log_2 p(x\mid y)/p(x)$；负 = 误导；平均非负；共现为 0 时无定义。
  4. 误导约束题：$p(x\mid y) < p(x)$ 解出一侧，表合法性给另一侧，取整。
  5. $I = 0$ ⟺ 独立；MI 是非线性的相关；混池熵不看时序。
  6. 交叉熵 = 按 $Q$ 编码的码长；KL = 多付的部分；MI = 联合与独立乘积之间的 KL。
